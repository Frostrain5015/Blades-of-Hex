# 阿克罗斯 RPG 原型

《六角之刃》的第二种玩法形态探索：把世界观从「指挥官视角的战争」下沉到「一个人的视角」。
2D 俯视、即时动作战斗、纯 Canvas 2D、零依赖。

与 [`../3d-battlefield/`](../3d-battlefield/) **平级并列且互不相干**——不进主包、不改 `server.js`、
不进 `vite.config.js` 构建入口、主菜单没有入口，可整目录删除而不影响游戏。

---

## 它要回答的那一个问题

> 在奥雷利亚的本格世界观里，把战棋的 `$` 经济缩到「个人尺度」并挂上装备与即时战斗后，
> 「攒钱 → 买装备 → 打得过之前打不过的敌人」这条 RPG 闭环，
> 能不能在 3 分钟内被玩家自发跑通？

产出是一个**决策**（保留／废弃／调参重试），不是产品。

## 运行

```bash
node prototype/akros-rpg/serve.mjs
# → http://127.0.0.1:8322/prototype/akros-rpg/index.html
```

`serve.mjs` 是零依赖静态服务器，以**仓库根**为根目录，因此页面能直接读
`/img/commander/百夫长.webp` 等既有立绘。端口可用 `PORT=8323` 覆盖。

验收（需另开终端，服务器保持运行）：

```bash
node prototype/akros-rpg/shoot.mjs
```

Playwright 无头跑一遍全流程：抓 console 错误、跑 18 项断言、出 14 张截图，
结果写进 `screenshots/report.json`（该目录已在 `.gitignore` 中）。
浏览器策略：系统 Chrome → 已缓存的 chromium → 都没有则输出 `no-browser` 并退出，**绝不联网安装**。

## 操作

| 输入 | 行为 |
|---|---|
| `WASD` / 方向键 | 行走 |
| 鼠标左键（可长按） | 【劈砍】朝鼠标方向的 90° 扇形普攻 |
| `1` | 【乘胜】突进斩，1.6 倍伤害；命中后 30%、击杀 100% 立即重置冷却 |
| `2` | 【结阵】举盾 1.2 秒减伤 70%，结束时击退身前敌人 |
| `E` | 与商人／NPC 交谈、推进对白、离开面板 |
| `I` | 行囊与装备 |
| `ESC` | 关闭面板 |

被动【老兵】：经验获取 ×2（直接沿用 `rules/commanders.js` 的 `veteranXpMultiplier`）。

## 世界观锚点

全部取自既有设定，未新造任何设定：

- **马库斯**，32 岁，东征军前卫百夫长，鸢尾誓章 **A-147**——《染血的鸢尾花》主线视角人物
- **王都阿克罗斯外城区**：街道狭窄、建筑密集，居民住楼上、底层为店铺与作坊，鸢尾花从沿街窗台上探出来
- **时点**：东征令刚下达，出征前的最后几天。军里只发口粮和绷带，刀和甲得自己备——这就是他花自己钱的理由
- **药婆伊蕾妮**、**码头搬运工**（阿格里乌斯的化名身份，不点破）是既有角色
- 配色取自 `VISUAL_DESIGN.md`：鸢尾红 `#9e3438`、深紫 `#5b3c72`、暖金 `#d5b56f`

**红线**：奥雷利亚是本格世俗王国，无超自然元素。敌人只有混混、醉兵、眼线，没有怪物。

## 货币尺度

锚点是 `rules/units.js` 的 `infantry: { cost: 8 }`——`$8` 招募一支步兵部队。
奥雷利亚百人队约 80 人，于是

> **$8 ÷ 80 人 ≈ $0.10／人** = 一名士兵的开拔装备 + 首月军饷

个人物价因此全部落在 `$0.01 – $5.00`，两位小数。起始资金 `$1.85`（半年军饷余额）——
买不起百夫长横剑，能买制式短剑或锁子甲，二选一就是第一个有意义的决策。

**金钱内部一律以整数「分」存储**（1 `$` = 100 分），只在显示层转字符串。
浮点数存钱会在反复买卖里累积成脏数据；`shoot.mjs` 对此有专门断言。

| `character.js` | base→derive、装备修饰层、军衔 XP、金钱、背包 |

| `serve.mjs` / `shoot.mjs` | 静态服务器 / 验收脚本 |

### 三条实现纪律

1. **base 是唯一真值。** 派生属性每次重算，绝不存为真值。
2. **装备走可逆的修饰层。** 装备 push 一条、卸下 pop 同一条，永不改写 base。
   `shoot.mjs` 断言「卸下后面板精确回到装备前」。
3. **不 import 主游戏模块。** 平衡数值从 `rules/` **复制**进 `data.js` 并注明来源
   （如 `COMBAT_BALANCE.float.attack`），保证本目录可随时整个删掉，也不会反向约束 `rules/` 的改动。
   唯一的跨目录引用是走 HTTP 的静态立绘。

## 保留／废弃判据

在动手做正式版之前，先按下面的信号做判断——不是按感觉：

- **保留**：一名没被讲解过的玩家 30 秒内自发走到商人并完成一次购买，
  且打完一场后自愿再打一场。
- **废弃**：装备提升在战斗里感觉不到差别（伤害曲线太平），
  或走路本身枯燥到玩家只想快进到战斗。
- **调参重试**：只是数值不对（攻速／冷却／敌人血量／价格）→ 改 `data.js` 再测。

判定为「保留」意味着**在正式项目里重写**，而不是把这份原型代码复制过去——
原型代码携带原型假设，照搬就是把假设一起搬进产品。
