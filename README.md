# 海克斯之剑 · Blades of Hex

六角格回合制策略对战游戏。红蓝双方（或三方）在随机生成的六边形地图上指挥步兵、骑兵、炮兵，利用兵种克制、地形优势、士气系统、天气变化、将领技能与对策卡击败对手。

支持**本地双人热座**、**单人 PVE**、**联网 2P / 3P**四种模式，以及战争迷雾遭遇战玩法。

---

## 快速开始

\# 浏览器访问 https://boh.frostrain.tech/

## 游戏流程

1. 首页选择游戏模式
2. 选将阶段：各方从随机分配的将领池中选定 1 名将领
3. 对局阶段：轮流行动，占领全部城市获胜

每回合可以自由组合：**移动 → 攻击 → 招募 → 使用对策卡**，完成后按 `E` 结束回合。

## 游戏模式

| 模式 | 描述 |
|------|------|
| 本地双人 | 同机热座，红蓝轮流操作 |
| 单人 PVE | 人类 vs Grok AI（进攻型），中立由 Claude AI（防守型）控制；支持简单 / 中等 / 困难三档 |
| 联网 2P | WebSocket 联机，支持断线重连、再来一局、游戏内聊天 |
| 联网 3P | 三方混战，投降方领土移交中立 AI，本方可继续观战 |

所有模式均可开启**遭遇战（战争迷雾）**子模式，地图被迷雾遮蔽，须通过单位视野或侦察卡揭示敌情。

联网模式最多支持 9 个同时在线房间（ID 1–9），空置 2 分钟后自动释放。

## 兵种

| 兵种 | HP | 攻击 | 防御 | 速度 | 射程 | 花费 | 招募地点 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|------|
| 步兵 | 200 | 40 | 5% | 5 | 1 | $8 | 城市 |
| 骑兵 | 150 | 50 | 5% | 8 | 1 | $10 | 城市 |
| 炮兵 | 100 | 60 | 0% | 3 | 2 | $12 | 城市 |

### 兵种被动

- **步兵·坚守**：位于城市时，防御力 +10%，攻击/反击造成的伤害提高 15%，反击浮动更高
- **骑兵·冲锋**：势能制——本回合每移动 1 格，造成的伤害提高 10%（上限 30%），雾天提升至 15%/格；回合结束消失
- **炮兵·远射**：位于山地时射程 +1（不与风天叠加）

### 克制关系

```
步兵 ──▶ 骑兵 ──▶ 炮兵 ──▶ 步兵
```

克制关系影响两层：**②增伤乘区**（顺克 +20% 伤害，逆克 −20% 伤害）与 **③暴击率**（顺克 +25%，逆克无法暴击）。暴击率统一由浮动倍率区间体现（阈值以上占比即暴击概率），不做独立随机判定。

### 伤害计算管线

伤害由 4 层乘区相乘得出（反击另乘 0.75）：

```
伤害 = 攻击力 × 增伤 × 暴击/浮动 × 防御
```

| 乘区 | 组成（层内相互加算） |
|------|------|
| ① 攻击力 | 基础面板 × 百分比加成 + 固定加成（将领 atkBonusPct、军衔2、圣骑士光环） |
| ② 增伤 | 兵种克制（顺克+20%/逆克−20%）、骑兵冲锋、城市攻坚、天气条件增伤、空军上校增伤、魔术师幻形 |
| ③ 暴击/浮动 | 浮动倍率区间随机取值；暴击率=阈值以上占比，由士气、克制（顺克+25%/逆克锁0）、军衔/将领/魔术师暴击率整体上移区间实现，无独立随机判定 |
| ④ 防御 | 地形、工事、兵种基础、军衔、士气、将领、铁卫灵光、停滞者力场、天气（1−Σ，封顶 70%） |

## 晋升系统

单位通过战斗积累经验晋升，获得永久属性加成。

### 经验来源

| 行为 | XP |
|------|:--:|
| 造成任意伤害 | +1 |
| 触发暴击 | +1（额外） |
| 击杀敌人 | +3 + 目标等级奖励 |
| 被连续攻击第 N 次 | +N−1 |
| 占领城市 | +5 |

击杀目标的等级奖励：新兵 +0，老兵 +2，精英 +5，王牌 +12，**传说 +20**。击杀携带将领的单位额外 +10。

### 等级

| 等级 | 所需 XP | 称号 | 加成 |
|:--:|:--:|------|------|
| 0 | 0 | 新兵 | — |
| 1 | 8 | 老兵 | 最大 HP +20（同时回复 20） |
| 2 | 18 | 精英 | ATK +10 |
| 3 | 30 | 王牌 | 防御 +10%，暴击率 +25% |
| 4 | 48 | 传说 | 每回合回复 15% 最大 HP，图标显示 ★ |

晋升时额外回复 30% 已损 HP，最高 4 级。

## 士气系统

| 等级 | 状态 | 暴击浮动 | 防御力 | 效果 |
|:--:|------|:--:|:--:|------|
| 3 | 士气上升 ▲ | lo+0.05, hi+0.10 | +5% | 金色图标，持续 2 回合 |
| 2 | 正常 | — | — | 默认状态 |
| 1 | 士气下降 ▼ | lo−0.05, hi−0.10 | −5% | 紫色图标 |
| 0 | 混乱 ？ | lo−0.10, hi−0.20 | −20% | 不可移动或攻击 |

士气不再直接增/减伤害，改为影响**暴击浮动倍率**（调整 lo/hi 范围，进而改变暴击概率和伤害浮动）。

**触发条件：**
- 击杀敌人 → 击杀者士气 +1
- 夹击（六角轴两端各有敌方单位）→ 士气上限锁定为 1
- 包围（6 个邻格全为敌方单位）→ 士气锁定为 0
- 谋士攻心 → 永久降低目标士气
- 圣骑士勇气灵光范围内的友军免疫夹击 / 包围造成的士气下降

| 持有城市数 | 回合收入 |
|:--:|:--:|
| 1 | $4 |
| 2 | $7 |
| 3 | $9 |

**对策卡抽牌**：每回合最多抽 2 张，第一张花费 $5，第二张花费 $10。手牌上限 3 张。

## AI 系统

### Claude AI（防守型）— 控制中立势力
- 仅在自己行政区内行动，不主动进攻玩家领土
- 优先守城，主动追击入侵者
- 城市受威胁时将伤员移出，招募新兵补防
- 保守评分选择目标，优先击杀低血量单位

### Grok AI（进攻型）— PVE 对手
- 阶段一：快速抢占中立城市建立经济跳板
- 阶段二：以中立城市为前哨，对玩家领土发起进攻
- 会优先使用雷击卡打击将领单位
- 每名将领有独立战术权重（如百夫长 1.4、狂战士 1.5）
- 自动激活主动技能（圣骑士至圣斩等）

## 遭遇战模式（战争迷雾）

创建 / 开始游戏时勾选「遭遇战」即可启用。

- 每个阵营独立维护可见格集合，仅能看到己方单位视野范围内的地块
- 未进入视野的将领显示为「?」，无法提前获知对手阵容
- 使用**侦察卡**可临时揭示目标区域，持续 1 回合
- 热座（本地双人）模式：换手时显示屏幕遮罩防止偷看
- 对局结束后可点击「查看完整棋局」关闭迷雾查看全图

点击右上角 ⚙ 图标打开设置面板：

| 设置项 | 说明 |
|------|------|
| 动画速度 | 0.6× / 1.0× / 1.8× |
| 回合闪光 | 切换回合时的全屏闪光效果 |
| 屏幕震动 | 攻击和击杀时的震屏效果 |
| 音效 | 全局音效开关 |
| 音量 | 音效音量调节 |

所有设置自动保存到浏览器 localStorage。

## 联机对战指南

### 主机方

1. `npm start` 或双击 `start.bat` 启动服务器
2. 浏览器打开 `http://localhost:3000`，点击 **联网对战**
3. 选择 2P 或 3P 及对战模式，创建房间
4. 等待对手加入，全员准备后自动开始

### 客机方

1. 浏览器打开 `http://<主机局域网IP>:3000`
2. 点击 **联网对战** → 选择房间 → 点击准备

### 联机特性

- 将领选择与部署完全同步（Player1 分配种子，广播给所有人）
- 每次操作均向服务端暂存完整游戏状态，断线后重连可恢复对局
- 断线自动重连，最多尝试 2 次（间隔 3 秒）；也可手动点击「重新连接」
- 三人模式支持投降后转为观战视角
- 支持再来一局，角色随机重分配

## 管理后台

独立 Web 管理面板，随游戏服务器一同启动。

- **地址**：`http://localhost:3099`
- **默认密码**：`admin`
- **功能**：房间管理（查看 / 强制关闭）、用户管理（查看 / 封禁 IP / 解封）、黑名单持久化、实时日志、服务器状态

## 技术栈

| 层 | 技术 |
|------|------|
| 前端渲染 | HTML5 Canvas 2D，ES Modules，无构建工具 |
| 动画 | GSAP（CDN）用于 UI 动效、发牌、将领入场动画 |
| 音效 | Howler.js + freesound.org 真实音频资源 |
| 联机 | Node.js + `ws` 库，轻量级 WebSocket 中继 |
| 持久化 | 浏览器 localStorage（设置） |
| 移动端 | 触屏支持，响应式布局 |

## 文件结构

```
├── server.js            # 主服务器：静态文件、WebSocket、房间管理
├── js/
│   ├── main.js          # 入口：大厅 UI、将领选择、网络回调、聊天
│   ├── gameLogic.js     # 核心游戏逻辑：地图、移动、攻击、回合、招募
│   ├── config.js        # 全局常量：兵种、地形、天气、对策卡、经济
│   ├── state.js         # 游戏状态、序列化/反序列化
│   ├── network.js       # WebSocket 封装：连接、断线重连、消息队列
│   ├── renderer.js      # Canvas 渲染：地块、单位、特效、迷雾
│   ├── effects.js       # 粒子特效、投射物、震动、金币雨
│   ├── audio.js         # 音频管理（Howler.js）
│   ├── fogOfWar.js      # 遭遇战视野计算
│   ├── input.js         # 鼠标 / 键盘 / 触屏输入处理
│   ├── ai.js            # AI 系统（Claude 防守型 + Grok 进攻型）
│   ├── HexTile.js       # 六角格类，边界计算
│   └── Unit.js          # 单位类，经验 / 晋升 / 技能触发
├── commander/
│   ├── index.js         # 将领注册表，随机分池逻辑
│   └── *.js             # 每名将领独立模块（18个文件）
├── admin/               # 管理后台（独立服务 + 页面）
├── img/commander/       # 将领立绘（.jpg）
├── img/commander_tr/    # 将领透明立绘（.png）
├── certs/               # TLS 证书（可选）
└── css/style.css        # 全局样式
```
