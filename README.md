# 海克斯之剑 · Blades of Hex

六角格回合制策略对战游戏。红蓝双方（或三方）在随机生成的六边形地图上招募步兵、骑兵、炮兵，利用兵种克制、地形优势、士气包围、天气变化与将领技能击败对手。

游戏支持**本地双人**、**单人 PVE**、**局域网联机（2人/3人）**三种模式。地图分为若干个行政区——，而胜利规则很简单————占领全部行政区即可获胜。

---

## 新手入门

### 一分钟上手

1. 双击 `start.bat` 启动服务器（或手动 `npm install && npm start`）
2. 浏览器打开 `http://localhost:3000`，点击 **开始游戏**
3. 进入大厅后选择游戏模式：**本地双人** / **单人PVE** / **联网对战**
4. 选择将领 → 挂载将领到单位 → 游戏开始

### 你的第一个回合

每回合可执行：**移动 → 攻击 → 招募**（顺序自由），完成后按 `E` 或 `Enter` 结束回合。

- **移动**：点击己方单位（可行动单位有脉冲光晕提示），蓝色格子为可达地块，点击目标移动
- **攻击**：移动后或选中单位后，红色光圈为可攻击目标，点击敌方单位发起攻击
- **招募**：点击己方城市，再按 `1`（步兵）、`2`（骑兵）、`3`（炮兵），消耗金币招募新单位，新单位当回合无法行动
- **结束回合**：按 `E` / `Enter`，或点击右下角"结束回合"按钮
- **撤销**（仅单机）：`Ctrl+Z` 撤销上一步操作

### 胜利条件

占领全部城市（使所有其他阵营失去行政区）即获胜。联机三人模式中，先消灭所有对手的玩家获胜；中途可投降，投降方领土移交中立AI。

## 游戏模式

| 模式 | 人数 | 说明 |
|------|:--:|------|
| 本地双人 | 2 | 同机热座，红蓝轮流操作 |
| 单人 PVE | 1 | 人类 vs Grok AI（进攻型），中立由 Claude AI（防守型）控制 |
| 联网 2P | 2 | 局域网联机，支持重赛、断线重连 |
| 联网 3P | 3 | 三人混战，三方将领均分，支持投降观战 |

联网模式通过 WebSocket 实时同步，支持最多 9 个房间（ID 1-9），房间空闲 15 分钟后自动回收。

## 兵种

| 兵种 | HP | 攻击 | 防御 | 速度 | 射程 | 价格 | 被动 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|------|
| 步兵 | 200 | 40 | 10% | 5 | 1 | 40 | **坚守**：位于城市时，每回合回复 10% HP（雨天 20%），防御 +20%，反击伤害提升 |
| 骑兵 | 125 | 50 | 5% | 8 | 1 | 50 | **冲锋**：本回合移动 ≥2 格后，伤害 +25%（雾天仅需 1 格且 +30%） |
| 炮兵 | 100 | 60 | 0% | 3 | 2 | 50 | **远射**：位于山地时射程 +1（不与风天叠加），无视目标 5% 防御 |

### 克制关系

```
步兵 → 骑兵 → 炮兵 → 步兵
```

- **顺克**（如步兵打骑兵）：伤害 ×1.25，暴击阈值降低至 1.50
- **平克**（同兵种或不相克）：正常伤害，暴击阈值 1.30
- **逆克**（如骑兵打步兵）：伤害 ×0.75，无法暴击

暴击由浮动倍率决定：正常浮动 0.85~1.35，顺克浮动 0.90~1.70。超过阈值即暴击。堕天使·黑形态暴击率 100%。

## 晋升系统

单位通过战斗获取经验（XP），达到阈值后晋升等级，获得永久属性加成。

### 经验获取

| 行为 | XP |
|------|:--:|
| 造成伤害（任意数值） | +1 |
| 暴击 | +1（额外） |
| 击杀敌人 | +3 + 目标等级奖励 |
| 被连续攻击（第 N 次） | +N−1 |
| 占领城市 | +5 |
| 百夫长加成 | ×1.5 |

目标等级奖励：新兵 +0，老兵 +2，精英 +5，王牌 +12。击杀携带将领的敌人额外 +10。

### 等级

| 等级 | 所需 XP | 称号 | 加成 |
|:--:|:--:|------|------|
| 0 | 0 | 新兵 | — |
| 1 | 8 | 老兵 | HP上限 +20（并回复 20 HP） |
| 2 | 18 | 精英 | ATK +10 |
| 3 | 30 | 王牌 | 防御 +10%，暴击率 +33% |
| 4 | 48 | 传说 | 每回合回复 15% 最大 HP，单位图标显示 ★ |

晋升时回复 30% 已损 HP。最高等级为 4 级。

## 士气系统

| 等级 | 名称 | 攻击倍率 | 防御 | 效果 |
|:--:|------|:--:|:--:|------|
| 3 | 士气上升 ▲ | 1.15× | +5% | 金色三角图标，持续 2 回合 |
| 2 | 正常 | 1.00× | — | 默认状态 |
| 1 | 士气下降 ▼ | 0.80× | −5% | 紫色三角图标 |
| 0 | 混乱 ？ | 0（无法行动） | −15% | 问号图标，不可移动或攻击 |

**士气变化触发条件：**
- 击杀敌人：击杀者士气 +1（被击杀者若携带将领，同阵营全体士气 +1）
- 夹击（六角轴两端有敌方单位）：士气上限锁定为 1
- 包围（6 个邻接格全为非己方单位）：士气锁定为 0
- 谋士攻心：永久降低目标士气
- 堕天使：士气变化时切换形态

## 地形

地图每局随机生成（森林约 8%、山地约 4%），城市固定为平原。

| 地形 | 防御 | 移动消耗 | 标识 |
|------|:--:|:--:|:--:|
| 平原 | — | 2 | 无 |
| 森林 | +10% | 3 | 🌲 |
| 山地 | +10% | 6 | ⛰ |
| 城市 | — | 2 | 🏰 |

- **移动消耗**：单位速度 = 行动力上限，每走一格消耗对应地形的移动消耗值
- **敌方控制区（ZoC）**：进入敌方单位邻接格时，剩余行动力清零

## 天气系统

前 2 回合为晴天（热身期），之后进入 2 回合天气 + 1 回合晴天的循环。天气不会连续出现相同的。

| 天气 | 效果 |
|------|------|
| ☀️ 晴天 | 无特殊效果 |
| 🌧 雨 | 骑兵每步移动消耗 +1 · 步兵守城回血提升至 20% · 雷击卡伤害翻倍 |
| 🌫 雾 | 炮兵射程 −1、伤害 −25% · 骑兵冲锋仅需移动 1 格即生效且伤害 +30% |
| 💨 风 | 炮兵射程 +1、伤害 +15% · 步兵无法暴击 |

## 经济系统

- **金币收入**（每回合开始）：1 城 = 20，2 城 = 35，3+ 城 = 45 + 10×(城数−2)
- 中立 AI 收入减半
- **攻城掠夺**：占领敌方城市时，掠夺其 50% 金币，剩余金币均分至其他城市
- 初始各阵营 60 金币

## AI 系统

游戏内置两个 AI，性格和策略截然不同：

### Claude AI（防守型）— 控制中立势力
- 仅在自己行政区内活动，不主动进攻玩家领土
- 优先防守城市，会主动追击入侵者
- 紧急换防：将受伤守军移出城市，招募新兵填补
- 使用保守评分选择目标，优先击杀而非冒险

### Grok AI（进攻型）— 控制 PVE 对手
- 阶段一：先攻占中立城市建立跳板
- 阶段二：以中立城市为前哨，推进敌方领土
- 会使用雷击卡，优先打击将领单位
- 每位将领有独立的战术权重（如百夫长攻击性 1.4、狂战士攻击性 1.5）
- 自动激活狂战士的主动技能

## 联机对战

### 主机

1. 确保服务器已启动（`npm start` 或双击 `start.bat`）
2. 浏览器打开 `http://localhost:3000`，点击 **联网对战**
3. 选择 2P 或 3P 模式，创建房间
4. 等待其他玩家加入，全员准备后自动开始

### 客机

1. 浏览器打开 `http://<主机IP>:3000`
2. 点击 **联网对战** → 选择自动扫描或手动输入 IP
3. 加入房间后点击准备，等待游戏开始

### 联机特性

- 将领选择与部署完全同步
- 游戏状态通过 WebSocket 实时传输
- 支持重赛功能
- 断线后自动重连（最多 2 次，间隔 5 秒）
- 三人模式支持投降观战

## 管理后台

独立的 Web 管理面板，用于运维和监控游戏服务器。

- 访问地址：`http://localhost:3099`
- 默认密码：`admin`
- 功能：服务器启停、房间管理（查看/强制关闭）、用户管理（查看/封禁 IP）、黑名单、实时日志、内存监控、客户缓存更新

管理后台服务随游戏服务器一同启动。

## 技术说明

- 纯前端 Canvas 渲染 + ES Modules，零构建工具
- 服务端 Node.js + ws 库，轻量级 WebSocket 中继
- 音效使用 Web Audio API 合成，无需音频文件
- GSAP（CDN）用于胜利动画等高级动效
- 支持移动端触屏操作
- 两个 AI 模块独立运作：Claude（防守型）与 Grok（进攻型）
- 持久化存储基于浏览器 localStorage
