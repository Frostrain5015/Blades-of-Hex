# 海克斯之剑 · Blades of Hex

六角格回合制策略对战游戏。红蓝双方在六边形地图上招募步兵、骑兵、炮兵，利用兵种克制、地形优势、士气包围等机制击败对手。

---

## 快速开始

### 单机双人对战
1. 浏览器打开 `http://localhost:3000`
2. 点击 **本地双人对战**
3. 同一台电脑，两人轮流操作

### 局域网联机

**主机：**
1. 启动服务器（见下方部署说明）
2. 浏览器打开 `http://localhost:3000`
3. 点击 **创建联网对战**，等待对手加入

**客机：**
1. 浏览器打开 `http://<主机IP>:3000`
2. 点击 **加入联网对战**
3. 点击 **自动扫描**（自动发现并连接主机），或 **手动连接** 输入主机 IP

双方到齐后服务器随机分配红蓝阵营，骰子转盘揭示身份后开始。

---

## 服务器部署

双击 `start.bat` 即可一键安装依赖并启动服务器。

或手动执行：

```bash
npm install
npm start
```

- HTTP 页面端口：`3000`
- WebSocket 联机端口：`8080`

## 兵种

| 兵种 | HP | 攻击 | 速度 | 射程 | 价格 | 技能 |
|------|:--:|:--:|:--:|:--:|:--:|------|
| 步兵 | 100 | 30 | 5 | 1 | 25 | **坚守**：位于城市时每回合回复 10% 生命，受到伤害−30%，反击暴击率提高至 50% |
| 骑兵 | 90 | 55 | 8 | 1 | 40 | **冲锋**：本回合移动至少 2 格后，造成伤害+25% |
| 炮兵 | 70 | 55 | 3 | 2 | 35 | **远射**：攻击时不会触发敌方反击 |

### 克制关系

```
步兵 → 骑兵 → 炮兵 → 步兵
```

顺克方向造成伤害+25%，逆克方向造成伤害−25%。暴击率受克制影响：顺克 40%、平 20%、逆克 5%。暴击伤害 1.5 倍，反击暴击 1.8 倍。

## 地形

地图每局随机生成，城市固定为平原。

| 地形 | 效果 | 标识 |
|------|------|:--:|
| 平原 | — | 无 |
| 森林 | 受到伤害−15%，移动较慢 | 🌲 |
| 山地 | 受到伤害−25%，移动缓慢 | ⛰ |
| 城市 | 步兵受到伤害额外−30% | 🏰 |

防御与步兵守城**加算**。步兵站在森林城市上承伤比例 = `1 − 0.30 − 0.15` = 0.55，即 45% 减伤。

## 士气

击杀敌方、被夹击、被包围会触发士气变化。每次攻击或移动后实时评估。

| 士气 | 效果 | 触发条件 | 角标 |
|------|------|------|:--:|
| 士气上升 | 攻击力+15% | 击杀敌方单位，持续 2 回合 | ▲ |
| 正常 | — | 默认状态 | — |
| 士气下降 | 攻击力−20% | 同一六角轴两端被敌方夹击 | ▼ |
| 混乱 | 无法操控 | 6 个邻接格全部为非己方单位 | ？ |

## 行政区与胜利条件

地图由 5 个 Voronoi 行政区组成，每区一座城市。攻占城市后整个行政区归进攻方所有。一方失去所有行政区即战败。

## 快捷键

| 按键 | 操作 |
|------|------|
| `1` `2` `3` | 招募步兵 / 骑兵 / 炮兵 |
| `E` / `Enter` | 结束回合 |
| `Escape` | 取消选中 |
| `Ctrl+Z` | 撤销上一步（仅单机） |
| `Ctrl+S` | 存档 |
| `Ctrl+L` | 读档 |
| `Ctrl+~` | 作弊控制台（仅单机） |

---

## 作弊控制台

单机模式下按 `Ctrl+~` 呼出，输入命令后回车。

| 命令 | 效果 |
|------|------|
| `/help` | 列出所有命令 |
| `/kill` | 击杀选中单位 |
| `/heal` | 选中单位血量回满 |
| `/morale high\|normal\|low\|chaos` | 设置士气 |
| `/god` | 切换无敌状态 |
| `/gold 100` | 当前阵营加金币 |
| `/spawn 步\|骑\|炮` | 在选中地块招募单位 |
