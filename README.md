# 海克斯之剑 · Blades of Hex

六角格回合制策略对战游戏。红蓝双方在随机生成的六边形地图上招募步兵、骑兵、炮兵，利用兵种克制、地形优势、士气包围、天气变化与将领技能击败对手。

游戏支持**单机双人**（同机热座）与**局域网联机**两种模式。地图分为 5 个行政区，其间驻扎着一支由 AI 操控的中立守军——占领全部行政区即可获胜。

---

## 新手入门

### 一分钟上手

1. 双击 `start.bat` 启动服务器（或手动 `npm install && npm start`）
2. 浏览器打开 `http://localhost:3000`，看到标题画面后点击 **开始游戏**
3. 进入游戏大厅，选择 **本地双人对战**
4. 关闭设置面板后，游戏开始

### 你的第一个回合

每回合你可以执行的操作为：**移动 → 攻击 → 招募**，顺序自由，完成后按 `E` 或 `Enter` 结束回合。

- **移动**：点击己方单位（可行动的单位有脉冲光晕提示），蓝色格子为可达地块，点击目标移动
- **攻击**：移动后，红色光圈为可攻击目标，点击敌方单位发起攻击
- **招募**：点击己方城市，再按 `1`（步兵）、`2`（骑兵）、`3`（炮兵），消耗响应金币招募新单位，新单位当回合无法立即行动
- **结束回合**：按 `E` / `Enter`，或点击右下角"结束回合"按钮

**中立势力**也会在自己的回合行动——它不是摆设，会主动防守自己的地盘。你可以先攻打中立城市来扩张领土和收入，但注意别让对手趁机偷家。

### 胜利条件

占领全部 5 座城市（使对手失去所有行政区）即获胜。也可以通过经济与兵力碾压迫使对方认输。

## 兵种

| 兵种 | HP | 攻击 | 速度 | 射程 | 价格 | 技能 |
|------|:--:|:--:|:--:|:--:|:--:|------|
| 步兵 | 100 | 30 | 5 | 1 | 30 | **坚守**：位于城市时，每回合回复 10% HP，受到伤害 −30%，反击暴击率约44% |
| 骑兵 | 90 | 55 | 8 | 1 | 40 | **冲锋**：本回合移动 ≥2 格后，造成伤害 +25% |
| 炮兵 | 70 | 55 | 3 | 2 | 35 | **远射**：攻击不触发敌方反击 |

### 克制关系

```
步兵 → 骑兵 → 炮兵 → 步兵
```

- **顺克**（如步兵打骑兵）：伤害 +25%，暴击率约33%
- **平克**（同兵种或不相克）：暴击率约10%
- **逆克**（如骑兵打步兵）：伤害 −25%，无法暴击

暴击由浮动倍率决定：顺克约33%暴击率，平克约10%，逆克无法暴击。反击暴击阈值1.50（城市反击约44%）。堕天使·黑暴击率100%。兵种克制是战斗的核心——用对兵种打对目标，事半功倍。

### 进阶技巧

- **步兵-守城中坚**：能力均衡，驻扎于城市时属性大幅增强，雨天额外加成
- **骑兵-突袭前锋**：适合抢占城市、侧翼包抄对方炮兵，雾天更强
- **炮兵-轰炸支援**：2 格射程，不会被反击，风天更强
- 被击杀时，击杀方单位会**士气上升**（攻击力 +15%，持续 2 回合）

## 地形

地图每局随机生成（森林 8%、山地 4%），城市为固定平原。

| 地形 | 减伤 | 移动消耗 | 标识 |
|------|:--:|:--:|:--:|
| 平原 | — | 2 | 无 |
| 森林 | 15% | 3 | 🌲 |
| 山地 | 25% | 6 | ⛰ |
| 城市 | — | 2 | 🏰 |

- **移动消耗**：单位速度 5 表示有 5 点行动力，每走一格消耗对应地形的 stepCost
- **敌方控制区（ZoC）**：进入敌方单位邻接格时，剩余行动力清零（无法继续移动）

## 士气

士气在每次攻击和移动后实时评估，影响战斗力和可操作性。

| 士气 | 效果 | 触发条件 |
|------|------|------|
| 士气上升 ▲ | 攻击力 +15% | 击杀敌方单位，持续 2 回合 |
| 正常 | — | 默认状态 |
| 士气下降 ▼ | 攻击力 −20% | 六角轴两端被敌方夹击 |
| 混乱 ？ | 无法操控 | 6 个邻接格全部为非己方单位 |

士气是突破僵局的关键。利用骑兵的高机动性实施**包围**（让敌方单位周围全是你的兵），可以废掉对方最强单位。

## 将领系统

双方在开局前各随机分配 3 名将领，从中选择 1 名出战。将领挂载到己方已有单位上，赋予该单位属性加成和专属技能。

将领单位头顶显示金色名称，阵亡后将领永久消失——保护将领至关重要。

| 将领 | 加成 | 技能 | 效果 |
|------|:--:|------|------|
| 谋士 | HP+15 ATK+5 | 攻心 | 攻击时 75% 概率降敌方士气一级；若目标已混乱则**感化为己方单位** |
| 铁卫 | HP+30 | 守护 | 自身承伤 −30%，每回合回复 40% 已损 HP；相邻友军承伤 −20% 且 50% 转由铁卫承担 |
| 吸血鬼 | ATK+10 | 嗜血 | 攻击和反击造成的伤害 25%~75% 转化为自身 HP |
| 停滞者 | HP+15 ATK+5 | 缚足 | 自身及相邻 6 格内敌军每步移动消耗 +3 |
| 百夫长 | ATK+5 | 乘胜追击 | 击杀敌人后 MP+3 且可再行动（每回合最多 1 次） |
| 尚书 | HP+10 | 屯田 | 驻扎城市时每回合 +10 金币，该城市招募费用 −20% |

### 将领选择建议

- **新手友好**：铁卫（生存强）、吸血鬼（续航强）
- **进攻型**：百夫长（连杀收割）、谋士（降士气+招降）
- **防守/经济型**：尚书（屯田爆钱）、停滞者（拖慢敌军）
- 联机对战时，将领选择在双方之间同步，确保公平

## 天气系统

前 2 回合为晴天（热身期），之后进入 2 回合天气 + 1 回合晴天的循环。

| 天气 | 效果 |
|------|------|
| ☀️ 晴天 | 无特殊效果 |
| 🌧 雨 | 骑兵每步移动消耗 +1 · 步兵守城回血提升至 20% |
| 🌫 雾 | 炮兵伤害 −25%、射程 −1 · 骑兵冲锋仅需移动 1 格即生效且伤害 +30% |
| 💨 风 | 炮兵射程 +1、伤害 +15% · 步兵无法暴击 |

天气会改变兵种强度——雨天利好步兵防守，雾天利好骑兵突袭，风天利好炮兵远程压制。注意利用天气窗口发起进攻或组织防御。

## 经济系统

- **金币收入**（每回合开始）：1 城 = 20，2 城 = 35，3 城及以上 = 20 + 15 + 10×(城数−2)
- 中立AI收入减半
- **攻城掠夺**：占领敌方城市时，抢走对方特定比例的金币
- 金币用于招募单位
- 初始各阵营 60 金币

**关键策略**：前期尽可能多占中立城市扩大经济优势。城市越多，每回合可招募的单位越多。

---

## 中立 AI

地图初始 5 座城市中，红蓝各占 1 座，其余 3 座由**中立 AI** 控制。三方的回合顺序为：玩家1 → 玩家2 → 中立 → 循环。

中立 AI 性格偏防守：
- 不主动进攻玩家领土，仅在自己的行政区内活动
- 优先防守城市，会主动追击进入领地的入侵者
- 有独立的收入系统（减半），会招募单位补充兵力
- 可以攻打中立城市来扩张领土——但小心螳螂捕蝉黄雀在后

## 操作指南

### 快捷键

| 按键 | 操作 |
|------|------|
| `1` `2` `3` | 招募步兵 / 骑兵 / 炮兵（需先选中己方城市） |
| `E` / `Enter` | 结束回合 |
| `Escape` | 取消选中 |
| `Ctrl+Z` | 撤销上一步（仅单机） |
| `Ctrl+S` | 手动存档 |
| `Ctrl+L` | 读档 |
| `` Ctrl+` `` | 作弊控制台（仅单机） |

### 鼠标操作

- **悬停地块**：显示详细 tooltip（单位属性、技能、士气、地形效果）
- **点击己方单位**：显示可移动范围（蓝色）和可攻击范围（黄色）
- **点击敌方/中立单位**：查看其信息（可用于侦查）
- **点击目标地块**：移动或攻击

### 游戏设置

点击右上角齿轮图标打开设置面板，可调整：

| 设置 | 说明 |
|------|------|
| 动画速度 | 0.5x ~ 2.0x，控制移动/攻击动画快慢 |
| 粒子密度 | 0% ~ 100%，控制特效数量 |
| 屏幕震动 | 攻击和击杀时的震屏效果开关 |
| 回合闪烁 | 回合切换时的闪屏提示开关 |
| 音效 | 合成音效开关 |

所有设置自动保存到浏览器。

## 联机对战

### 主机（创建房间）

1. 确保服务器已启动（`npm start` 或双击 `start.bat`）
2. 浏览器打开 `http://localhost:3000`，点击 **创建联网对战**
3. 进入准备阶段，等待对手加入

### 客机（加入房间）

1. 浏览器打开 `http://<主机IP>:3000`
2. 点击 **加入联网对战**
3. 方式一：点击 **自动扫描**，自动发现局域网内主机
4. 方式二：点击 **手动连接**，输入主机 IP 地址后确认

### 联机流程

1. 客机加入后，服务器随机分配红蓝阵营
2. 骰子转盘揭示双方身份
3. 双方各自从随机 3 名将领中选择 1 名
4. 双方将将领挂载到己方单位上完成部署
5. 游戏开始，红军先手

### 联机特性

- 将领选择与部署完全同步
- 游戏状态通过 WebSocket 实时传输
- 支持重赛功能
- 断线后对手会收到提示
- 不支持撤销（Ctrl+Z），不支持存档作弊

---

## 存档与读档

- **手动存档**：`Ctrl+S`，将当前游戏状态保存到浏览器 localStorage
- **读档**：`Ctrl+L`，从浏览器恢复之前保存的游戏
- **自动存档**：单机模式下每回合切换时自动保存
- 仅单机模式可用（联机模式禁用存档功能）

## 作弊控制台

单机模式下按 `` Ctrl+` `` 呼出，输入命令后回车。

| 命令 | 效果 |
|------|------|
| `/help` | 列出所有可用命令 |
| `/kill` | 击杀当前选中单位 |
| `/heal` | 选中单位 HP 回满 |
| `/morale high\|normal\|low\|chaos` | 设置选中单位士气 |
| `/god` | 切换无敌状态（选中单位不受伤害） |
| `/gold 100` | 当前阵营加金币 |
| `/spawn 步\|骑\|炮` | 在选中地块招募指定兵种 |
| `/weather clear\|rain\|fog\|wind` | 强制设置天气 |

## 技术说明

- 纯前端 Canvas 渲染 + ES Modules，零构建工具
- 服务端 Node.js + ws 库，轻量级 WebSocket 中继
- 音效使用 Web Audio API 合成，无需音频文件
- GSAP（CDN）用于胜利动画等高级动效
- 支持移动端触屏操作
