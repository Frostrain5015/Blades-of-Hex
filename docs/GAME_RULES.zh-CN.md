## 第一章：回合结构与胜负判定

- **行动顺序**：每局开始随机决定各玩家阵营的先后手轮转次序；存在中立守军的地图上，**中立 AI**（`neutral`）在所有玩家行动结束后压轴执行。场上所有活跃阵营各行动一次，合称 **1 轮（Round）**。
- **单回合行动节拍**：每支部队每回合可先机动（按自身移速消耗行动力），再执行战斗、构筑工事或发动主动技能。
- **出局与灭国判定（标准遭遇战 / 联机对战）**：
  - 任一阵营一旦失去全部**陆地行政区**即刻判负。（仅占领海上孤立港口无法维持阵营存续。）
  - **三人对局**中，出局阵营的残余部队立刻移交中立 AI 接管，所占港口同步归还中立；坚持到最后的玩家获胜。
- **回合时钟决胜**：
  - **二人遭遇战**：第 **19** 轮触发回合限制结算。
  - **三人遭遇战**：第 **26** 轮触发回合限制结算。
  - 仍存活的非中立阵营中，控制**城市数量最多**的一方胜出；若领跑者城市数相同，则判为平局。
- **将星列传（单人战役）**：胜负与撤退条件由关卡脚本目标独立裁决，不适用常规行政区灭国或固定回合限制。

> **指挥官锦囊**：时刻留意顶部回合数！当对局逼近第 19 轮（三人局第 26 轮）时，城市数量领先便是硬道理——及时从无谓的深追转为固守残血前线城。切记，哪怕舰队仍称霸大洋，只要最后一块陆地行政区易主，战局就会立刻宣告结束！

## 第二章：经济体系、领土收益与招募

### 金币收入来源

| 收入来源 | 每回合金币 | 规则说明 |
| --- | --- | --- |
| 第 1 座城市 | `$4` | `firstCityGold` |
| 第 2 座城市 | `$3` | `secondCityGold`（双城合计 `$7`） |
| 其余每座城市 | `$2` | `additionalCityGold`（3 城 `$9`，4 城 `$11`，依此类推） |
| 每座村庄 | `$1` | `villageGold`（村庄间距至少 `3` 格） |

- **中立 AI 经济倍率**：中立阵营先汇总城市与村庄产出，再统一乘以 `NEUTRAL_ECONOMY_RATE = 0.2`（20% 下取整）。
- **招募规则**：
  - **城市**：招募地面部队（采用美国历史文化时亦可在城中招募海军陆战队）。
  - **己方可用港口**：建造各类海军舰船（驱逐舰、巡洋舰、潜艇、航空母舰、皇家战列舰）及美国海军陆战队。
  - 招募或建造点当前必须空置，且未处于空袭瘫痪期内。
- **选将与重抽**：
  - **单将模式**：每名玩家 `3` 选 `1`。
  - **双将模式**：每名玩家 `5` 选 `2`。
  - 重抽换将费用：**`$3`**。

> **指挥官锦囊**：别看单座村庄每回合只给 `$1`，一盘 15 轮下来，开局抢下 3 座村庄就能多赚 `$45`——足够拉起一支巡洋舰编队外加机场！前两回合善用高机动骑兵横扫周边中立村落，同时在前线空城承压时常备至少 `$8`，关键时刻随时拍出步兵守城。

## 第三章：地形、天气与士气机制

### 地形与野战工事

| 地形 / 工事 | 防御加成 | 移动步耗 | 实战定位 |
| --- | --- | --- | --- |
| 平原 | `0%` | `2` 点 | 利于大军快速穿插与机动 |
| 森林 | `+5%`（对远程再 `+15%`） | `3` 点 | 步兵躲避炮火的天然掩体 |
| 山地 | `+5%` | `6` 点 | 高消耗天然险要与阻滞带 |
| 战壕（`trench`） | 对近战 `+25%` | — | 地面部队就地构筑，专克骑兵与近战强冲 |
| 高射机枪（`flak`） | 自身 `+30%` 防空减伤 | — | 地面部队就地架设，抵御空袭与舰载机 |

> 所有百分比防御减免叠加后存在 **`85%`** 上限（最低承伤倍率 `0.15`）。

### 士气等级

| 等级 | 状态 | 攻击修正 | 行动限制 |
| --- | --- | --- | --- |
| `3` | 士气高昂 | `+20%` | 无 |
| `2` | 正常 | `0%` | 无 |
| `1` | 士气低落 | `-20%` | 无 |
| `0` | 混乱 | `0%` | 无法移动、主动攻击或反击 |

- **夹击与包围**：敌军在目标两侧或周围形成夹击阵型时，会即时施加站位士气惩罚（夹击 `-1`、包围 `-2`）；一旦外围敌军被清退或脱身，站位惩罚随即自动解除。

### 天气轮转规律

遭遇战前 **2 轮**固定为**晴天**（`warmupRounds = 2`），之后按 **2 轮特殊天气 + 1 轮晴天** 的节奏循环更替。

| 天气 | 战场效果 |
| --- | --- |
| **晴** | 标准气候，无额外修正。 |
| **雨** | 驻城部队每轮回复 `15%` 最大生命值；步兵守城防御 `+10%`；骑兵每步多耗 `1` 点行动力。 |
| **雾** | 炮兵、海军与固定防御建筑射程 `-1`；骑兵伤害提高 `20%`，且每步冲锋额外 `+5%`（变为每格 `15%`）。 |
| **风** | 炮兵射程 `+1`、伤害提高 `20%`；步兵防御降低 `15%`。 |
| **血月** | 敌方单位（相对诺克提斯施放者）无法回血；全场生命值 `<= 50%` 的单位每整轮损失已损生命值的 `1/3`（真实伤害）。 |

> **指挥官锦囊**：别让步兵在平原上硬吃敌方炮击，退进**森林**即可白拿共计 `+20%` 的远程减伤！接战前也先看一眼站位：只要友军绕侧形成夹击把敌方主力打成低士气甚至**混乱**，不仅对方火力骤降，你还能零反伤白嫖一轮集火！

## 第四章：战斗结算、军衔晋升与专精分支

### 战斗管线核心规则

- **兵种克制倍率**：交战双方依据克制表应用 `1.25x`（克制）、`1.0x`（均势）或 `0.75x`（被克）。克制方不仅伤害区间上浮，还额外获得 **`+40%` 克制暴击加成**；被克方则承受 `-40%` 的伤害浮动惩罚。
- **步兵守城特性**：步兵驻城时每轮自动回复 `10%` 最大生命，且城市与城区作战伤害 `+15%`。
- **骑兵冲锋**：发起攻击前每机动 1 格获得 `+10%` 伤害（雾天提升至 `+15%`），最多叠加 `3` 层。
- **反击机制**：处于射程内的守方默认会还击，但处于**混乱**状态或刚刚涉水登岸的单位无法反击。

### 军衔经验与专精晋升

- **经验阈值**：晋升 1 至 4 阶所需经验分别为 `[5, 15, 25, 35]`。
- **升级回血**：每次升阶立即恢复已损失生命值的 **`25%`**。
- **1 阶专精**：步兵、骑兵、炮兵、驱逐舰、巡洋舰在升至 1 阶时永久二选一晋升专精。
- **2 阶强化**：额外获得 **`+15` 最大生命** 与 **`+10` 攻击力**（防御建筑等固定单位锁阶）。
- **4 阶统帅级**：暴击率 **`+25%`**，且每轮自动回复 **`15%` 最大生命**。

| 基础兵种 | 专精分支 A | 专精分支 B |
| --- | --- | --- |
| **步兵** | **卫戍步兵**（`200` 血 / `40` 攻 / `10%` 防 / `4` 速）：城内回血再 `+10%`/`+20%`；每轮首击减伤 `15%`/`25%` | **突击步兵**（`180` 血 / `48` 攻 / `5%` 防 / `6` 速）：对工事增伤 `20%`/`35%`；击杀回复 `10%`/`20%` 生命 |
| **骑兵** | **轻骑兵**（`150` 血 / `55` 攻 / `5%` 防 / `9` 速）：每步冲锋 `10%`/`15%`（上限 3 层）；遭遇战视野 `+1` | **重骑兵**（`170` 血 / `50` 攻 / `10%` 防 / `5` 速）：所受反击减伤 `25%`/`40%`；远程穿甲 `10%`/`15%` |
| **炮兵** | **野战炮**（`100` 血 / `60` 攻 / `0%` 防 / `3` 速）：无视 `8%`/`12%` 防御（地形加成或风天翻倍） | **防空炮**（`110` 血 / `45` 攻 / `5%` 防 / `4` 速）：为周身 `2` 格内友军提供 `35%`/`50%` 防空庇护 |
| **驱逐舰** | **防空驱逐舰**（`140` 血 / `40` 攻 / `5%` 防 / `6` 速）：为周身 `2` 格内友军提供 `35%`/`50%` 防空庇护 | **反潜驱逐舰**（`150` 血 / `40` 攻 / `5%` 防 / `7` 速）：探测 `2` 格内潜艇；对潜伤害 `+30%`/`+50%` |
| **巡洋舰** | **制海型巡洋舰**（`200` 血 / `55` 攻 / `10%` 防 / `4` 速）：对舰伤害 `+25%`/`+40%`；`25%`/`40%` 概率追加 `50%` 副炮齐射 | **支援型巡洋舰**（`180` 血 / `60` 攻 / `5%` 防 / `5` 速 / `3` 射程）：攻陆额外 `+50%`；`25%`/`40%` 概率触发 `30%` 岸防溅射 |

> **指挥官锦囊**：善用升阶瞬间的 **`25%` 已损生命回复**！当一名 4/5 经验的残血单位收掉残敌迈入 1 阶时，既能白赚一口强力救急奶，又能立刻挑中专精质变。看到对手起机场或出航母时，尽早点出一门**防空炮**或**防空驱逐舰**往往能拯救整条战线的核心将领。

- **海岸封锁**：**岸防炮**对一切水面及水下舰船均享 `1.25x` 克制倍率。

> **指挥官锦囊**：普通炮兵仅有 `90` 点生命值，千万别把它裸露在敌方骑兵的突击路径上！永远用步兵或碉堡卡住前排半步，只要骑兵借不到冲锋路径，炮兵就能安稳地把敌方重甲阵线撕成碎片。

## 第六章：海战、两栖登陆与水文渡河

### 海陆跨域交战修正（`rules/naval.js`）

- **军舰打陆军**：伤害固定 `-50%`。（但巡洋舰、战列舰攻击空城建筑血池时享有 `+50%` 火炮攻城加成，两者抵消后恢复正常攻城效率。）
- **陆军打军舰**：伤害固定 `-50%`。
- **岸防炮**：攻击舰船 `+30%`，攻击陆军 `-60%`；建成后沿海同区域共享 `2` 轮建造冷却。

### 运输船与上下船规则

常规陆军部队（移速 `> 0`，无人机除外）踏入水域即转为**运输状态**：
- **移速上限**：封顶为 **`4`** 点。
- **属性大幅削弱**：基础攻击强制锁定为 **`20`**，射程锁定为 **`1`**。
- **防御重挫**：浅水区基础防御 **`-25%`**，**深水区直接 `-50%`**！
- **滩涂下水滞留**：从普通海岸涉水登船会**耗尽本回合剩余全部行动力**；若经由己方**港口**入海则免除此惩罚。
- **抢滩冷却**：部队由海面登岸的当回合无法发起攻击或反击。
- 美国专属兵种 **海军陆战队**（`amphibious`）是唯一无视上述水上减益与 `-50%` 海陆减伤的单位。

### 潜艇隐匿与港口机制

- **水下隐形**：潜艇平时不可被选作主攻目标，唯有进入敌方探测船（驱逐舰、反潜驱逐舰、皇家战列舰）`2` 格半径内，或是在攻击港口 / 占领与驶离港口后才会暂时暴露 **`2` 轮**。
- **港口控制**：夺取港口后触发 `1` 轮护港保护期；舰船停靠在己方正常运作的港口可花钱维修回血。

### 河流地形与水闸规则（`rules/movement.js`）

- **桥梁（Bridge）**：过河额外耗费 `+0` 点行动力。
- **浅滩（Ford）**：过河额外耗费 `+2` 点行动力。
- **无桥强渡**：跨过普通河段将立即清空剩余全部行动力。
- **淹没河道（Flooded）**：如《河谷防线》泄洪期间的水闸河段，完全不可通行。

> **指挥官锦囊**：陆军单位在海上运输时十分脆弱（攻击跌到 `20`、深水防御 `-50%`），**千万不要单独派运输船孤军渡海，一定要记得搭配驱逐舰或巡洋舰护航哦！** 驱逐舰能帮你提前照出蹲在航道上的潜艇，而尽量从**己方港口**下水则能让你在同一回合直接扬帆远遁，避免在岸边白白挨打。抢滩上岸的当回合也记得留意安全——落脚那一回合你是还不了手的！

## 第七章：城市攻坚、工程建设与空军行动

### 城市结构血池与破城占领（`rules/citySiege.js`）

- 每座城市（含大型多层城郭）共享同一个结构生命池：**半径 `0` 为 `250` HP**，每向外扩展一圈多 **`+200` HP**（半径 `1` 为 `450`，半径 `2` 为 `650`），且每轮自动修复 `10%` 最大城防。
