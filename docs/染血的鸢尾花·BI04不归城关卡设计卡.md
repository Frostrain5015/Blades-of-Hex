# 《染血的鸢尾花》BI-04《不归城》关卡设计卡

## 1. 核心体验

玩家突然失去马库斯视角，成为此前被称为“叛臣”的卡托。在真正的攻城主力抵达前，玩家必须把一座仍在运转的城市拆成四项可以完成的任务：让百姓知道往哪里走、让敌人找不到该清算谁、让西门继续吸引注意、让唯一的证词离开。

- **体验承诺**：大战尚未开始，但每一轮都能看见它更近一步。
- **叙事误读**：玩家亲手焚毁证据，却暂时不知道卡托保住了什么。
- **失败感受**：不是“杀敌不够快”，而是某条撤离链因调度失误断裂。

## 2. 地图规格与空间结构

- 布局：`borderless`，277 个有效格。
- 回合上限：8。
- 大型城市：中心 `(0,0)`，半径 2，共十九格并共享城防血池。
- 西缘：东征军营城、三路初始部队与六轮增援源头。
- 中央：佩特拉大型城市、三处档案点与主要守军。
- 北缘：北区撤离烽火，由北区弓手负责。
- 南缘：南区撤离烽火，由南区骑手负责。
- 东缘：密道出口 `(9,-2)`，由疏林围合但保持入口清楚。

关键任务地标的坐标跨度至少为东西 17 格、南北 12 格，确保任务真正利用无边地图，而不是只把装饰铺到边缘。

## 3. 黄金路径与玩家分工

推荐但不强制的黄金路径：

1. 西门三人进入战壕，延缓正面军势。
2. 北弓手和南骑手分别奔赴两座烽火。
3. 卡托与伊蕾妮在城内分头处理三处档案。
4. 城内弓手补防西门，东侧守军向密道方向建立接应线。
5. 五个交互点全部完成后，伊蕾妮从中央穿越东郊抵达密道。
6. 守军继续坚持至第七个佩特拉回合开始。

允许玩家改变顺序，但不能通过只执行一条任务线或原地等待获胜。

## 4. 节奏曲线

| 阶段 | 预计时间 | 强度 | 内容 |
|---|---:|---:|---|
| 黄昏命令 | 1–2 分钟 | 0.25 | 建立六轮倒计时、四线任务与卡托立场 |
| 第一轮展开 | 2 分钟 | 0.45 | 分兵、处理首批档案、敌军试探 |
| 两翼受压 | 2–3 分钟 | 0.60 | 点燃烽火、骑兵绕行、城防开始受损 |
| 城内火起 | 2 分钟 | 0.50 | 档案完成，短暂叙事释放，开放护送 |
| 横穿佩特拉 | 2–3 分钟 | 0.75 | 伊蕾妮向东移动，守军继续应对增援 |
| 主旗抵达 | 1–2 分钟 | 0.95 | 攻城锤、火箭与主旗依次进入叙事，完成六轮坚守 |

标准路线目标为 10–15 分钟。自动化只能验证空间跨度、回合门槛与任务数量，实际时长必须通过真人试玩确认。

## 5. 战前压力的可感知递进

1. 第一轮：敌军试探换防路线。
2. 第二轮：弓手测量烽火与城门距离。
3. 第三轮：骑兵绕行，切断南北撤离道路。
4. 第四轮：鼓声停止，攻城锤出现。
5. 第五轮：油布火箭准备焚城。
6. 第六轮：东征军主旗出现，揭示此前只是前导部队。

每轮从不同西侧坐标生成部队，避免“同一个洞口刷怪”的人工感。

  └─ __confirm_west_gate

关键状态改变发生在跳转或交互动作上，不依赖可重复显示的普通台词，以免重复写入变量。

## 7. 实现不变量

- **RULE-MAP-01**：`board.layout` 必须为 `borderless`，有效格数必须为 277。
- **RULE-CITY-01**：佩特拉城市半径必须为 2，十九格共享同一城防血池；城市被东征军占领立即失败。
- **RULE-DURATION-01**：必须经历六个完整敌军回合后，坚守目标才可完成；回合上限不得低于 8。
- **RULE-NO-IDLE-01**：胜利至少需要完成五个指定交互、一次跨图护送和六轮坚守，原地等待只能得到未完成或失败结果。
- **RULE-ESCORT-01**：只有 `archives_burned >= 3` 且 `beacons_lit >= 2` 时才能启用密道抵达触发器。
- **RULE-PRESSURE-01**：六轮增援必须使用唯一单位 ID，并从至少三个不同方向带进入场。
- **RULE-NARRATIVE-01**：对白只说明角色当下知道的事实；封蜡匣内容不得在本关提前揭示。

## 8. 视觉验收

- 无 HUD 截图中，两秒内能辨认中央大型城市、西侧敌军压力和东侧逃生方向。
- 北山脊、南林带和东疏林形成三个不同轮廓，不能均匀撒点。
- 西门战壕形成连续防线，但不得堵死所有通路。
- 城内档案区域保持低噪声，单位与交互高亮不被树林或山体遮蔽。
- 六轮敌军部署在地图上形成逐渐扩大的扇面，主力抵达前的空白纵深应被理解为“军势正在接近”，而不是未设计区域。

## 9. 验证清单

- Schema v4 零错误、零警告。
- 277 个有效格、十九格大型城市。
- 任务地标覆盖东西与南北轴。
- 五项交互缺一不可。
- 六轮增援按 `0–5` 轮次递进。
- 伊蕾妮在准备完成前无法触发密道。
- 伊蕾妮阵亡或佩特拉陷落立即失败。
- 真人标准路线达到 10–15 分钟。
