# Blades of Hex —— WC4 借鉴方向实施计划 v2

> 状态：结构规则已按“0阶标准型、1阶专精”更新；专精面板与1–4阶具体数值等待下一轮手动修正。替代 radiant-cascade-newton.md 作为后续实现依据。
>
> 核心目标：在保留现有六角格陆海战主体的前提下，引入真正的兵种横向选择、WC4 式空军指令、明确的点防空/区域防空分工，以及可由 AI、联机和战役共同使用的统一规则入口。

## 一、v2 已确认的设计决策

1. 所有常规兵种都以 0 阶标准型招募；招募面板不再直接展示或选择变体。
2. 0 阶单位不附带任何正向兵种被动，只保留基础面板、移动领域、攻击目标限制等物理规则。
3. 有专精分支的兵种在达到 1 阶时，通过右下角主动技能区选择一个专精；专精继续共享基础兵种 type 和 COUNTER_RELATION 行列，不扩张克制矩阵。
4. 潜艇和航母等无分支常规单位达到 1 阶时自动强化自身既有职能，不弹出选择；防空炮是炮兵的第三个专精分支；所有建筑单位一律不参与 XP、军衔和专精。
5. 野战炮和火箭炮都取消防空能力：
   - 野战炮负责单体穿甲。
   - 火箭炮负责范围压制。
6. 炮兵在 1 阶开放野战炮、火箭炮与防空炮三个专精分支；防空炮只能防空，不能攻击地面或海上目标。
7. 高射机枪工事保持 2 金币、永久、只保护所在单格。
8. 空军不拥有 HP，不占棋盘，也不会成为普通攻击目标；所有常规空军均为即时指令。
9. 空军指令由机场提供，不再依赖空军将领；空军将领只强化所在机场发动的指令。
10. 空运取消，改为空降；空降生成 0 阶标准步兵，由其后续通过战斗晋升并选择专精，不直接生成突击步兵。
11. 遭遇战额外开放侦察机指令，删除现有侦察对策卡。
12. 扫射与轰炸分别记录独立的两回合冷却。
13. 航母无舰炮和反击，只能以普通远程攻击的锁定形式发动单点扫射。
14. 原计划的地形专精被动整组取消。
15. 新增只能建在城市上的机场；标准对局每个阵营预置一座，机场上限为 ceil(城市数 / 3)。
16. 机场使用独立的城市设施槽，可与战壕或高射机枪共存；战壕与高射机枪共用地面工事槽并互斥。
17. 工事建造从工程师专属能力改为阵营通用建设；碉堡价格提高到 10 金币，仍需一回合完成，但不再锁定建造者下一回合。
18. 工程师重做为建设折扣、战地抢修和驻城机场防护特化的工兵将领。
19. 删除闪击与乘胜追击，新增具有持续伤害和邻接传播机制的对策卡“投毒”；通过增加地雷数量补足 20 张标准牌组，不再预留第二张新卡槽位。

## 二、旧计划审计与取舍

| 原设计 | v2 结论 | 原因 |
|---|---|---|
| 兵种子变体 | 改为 1 阶专精 | 保留横向选择，但从招募面板移至单位成长，避免扩大招募 UI |
| 正规步兵/标准驱逐舰继续存在 | 仅作为 0 阶标准型 | 0 阶无被动；达到 1 阶后选择专精或自动强化 |
| 野战炮和火箭炮沿用炮兵通用防空 | 取消 | 炮兵地面职能与防空职能应解耦 |
| 高射机枪同时提供远程防御和防空 | 收窄 | 2 金币永久工事不应同时承担廉价强掩体和点防空 |
| 闪电突袭免反击卡 | 取消 | 机制仍是一次性伤害规避，缺少新的战场互动 |
| 地形专精全兵种 +10% | 取消 | 与天气、工事、军衔专精继续加算会形成隐蔽叠层，并制造固定最优站位 |
| 乘胜追击恢复 50% MP | 取消 | 与强行军、百夫长和再行动体系重叠，新意不足且容易制造行动经济爆发 |
| 航母回合开始随机造成固定 30 伤害 | 取消 | 改为可预览、可锁定的单点扫射普通攻击 |
| 空军卡进入手牌 | 取消 | 空军改为机场的金币主动技能，不占牌库和卡牌使用次数 |
| 空运友军 | 取消 | 战略转移过强且边界复杂，改为有成本的 0 阶标准步兵空降 |
| 侦察卡作为遭遇战额外牌 | 取消 | 改为遭遇战机场的侦察机指令 |
| 空军指令依赖空军上校部署 | 取消 | 机场本身提供指令；空军将领只强化威力、范围和空降质量 |
| 工事由工程师独占 | 取消 | 战壕、高射机枪、碉堡改为所有阵营的通用建设 |
| 工程师施工碉堡期间锁定一回合 | 取消 | 建造者只消耗发起施工的当前行动，脚手架独立等待一回合 |

## 三、兵种专精与晋升体系 v2

### 3.1 通用规则

- UNIT_CONFIG 保存 0 阶标准型基础面板、独立兵种和旧内容兼容数据。
- UNIT_SPECIALIZATION_CONFIG 保存各兵种的专精分支、逐阶奖励和能力标签；本计划现有数值均为待手动校准草案，校准完成前不得视为最终实现常量。
- unit.type 始终是基础类型，例如两个骑兵专精的 type 都是 cavalry。
- unit.specializationKey 标识 1 阶后选择的专精；0 阶及待选择状态为 null。已晋升待专精的单位前端应有相应视觉提示，引起玩家注意。
- 同一兵种家族只共同继承 COUNTER_RELATION、移动领域和攻击目标限制等结构规则；0 阶不能因为 unit.type 相同而自动获得任何正向兵种被动。
- 移动领域、可攻击目标等物理分类仍可由家族共享，但它们属于单位合法性约束，不视为需要保留的“兵种被动”。
- 将领、天气等外部规则可以按 unit.type 筛选作用对象，但专精面板修正、被动、名称后缀和能力标签必须读取 specializationKey。
- 所有原先写死为 `unit.type === ...` 的正向兵种被动都要审计并从 0 阶移除，迁移到 specializationKey 或无分支兵种的 rank reward；负面限制和物理合法性不算被动。
- 新招募单位必须以 specializationKey = null、rank = 0 创建，不允许在招募阶段预选专精。

### 3.1.1 四阶奖励合同

旧版统一奖励全部废弃：不再使用 1 阶最大 HP +20、2 阶 ATK +10、3 阶防御 +10%/暴击 +25%、4 阶每回合回复 15%，晋升时也不再统一回复 30% 已损生命。

| 阶级  | 新奖励职责                                           |
| :-: | ----------------------------------------------- |
|  0  | 标准型；只有基础面板和结构规则，不显示兵种被动                         |
|  1  | 有分支兵种进入待选择状态；选择后获得专精一级面板修正和首个被动。无分支兵种自动获得一级职能强化 |
|  2  | 获得通用面板数值加成（HP+15，ATK+10，该数值待内测校正）               |
|  3  | 自动二次强化已选专精的核心被动；无分支兵种强化既有职能                     |
|  4  | 保留通用“再生”的情况下继续强化面板基础数值（建议强化暴击率）                 |

- XP 阈值暂时沿用 8 / 18 / 30 / 48，待数值校准阶段单独决定是否调整。
- 达到 1 阶但尚未选择时，单位可以继续行动和积累 XP，但不获得任何 1 阶及后续奖励。
- 玩家完成选择后，一次性补发该专精截至当前军衔应有的全部奖励。
- 专精选择不可逆；联机中必须作为独立确定性 action 广播。
- 增加最大生命时，只给当前生命增加同等的面板增量，不按比例治疗，不触发额外晋升回血。
- 一次 XP 结算无论跨越多少个军衔阈值，最多只触发一次“恢复 25% 已损生命”；回血在本次全部军衔与面板变更完成后结算。补选专精、载入重算、旧存档迁移和脚本直接设置 rank 均不触发晋升回血。
- AI 控制单位达到 1 阶后应立即按战场评分选择；中立或脚本单位可由关卡显式预设，否则使用规则层提供的确定性默认分支。

### 3.1.2 专精 UI

- 0 阶不在兵种被动区显示任何被动图标，单位详情也不作额外提示。
- 达到 1 阶且 specializationKey 为空时，右下角主动技能区按该兵种实际分支数显示专精按钮；炮兵显示三个，其余当前有分支兵种显示两个。
- 按钮不需要太详细，只需写类似“专精为卫戍步兵/突击步兵”即可，控制卡片长度
- 确认后专精按钮消失，已解锁能力进入左下角兵种被动区。
- 无分支兵种不显示选择按钮，在晋升结算中自动应用对应 rank reward。
- 专精时应有相应广播动画。

下列各兵种表格与被动描述先作为专精方向草案保留。所有 HP、ATK、DEF、SPD、费用、倍率、范围和逐阶增量都标记为“待手动数值修正”。
**注意：有斜杠的数值代表前面那个是1阶初始数值，后面那个是3阶强化后数值**

各表 COST 列不再是专精独立价格：招募费用由 0 阶基础 type 决定，各专精均继承已经支付的基础费用。以下括号中标有备注二字的括号内容均不进入前端文案。
全局修改：晋升时恢复已损生命值的机制数值削弱到25%并彻底取消防空火力的“层数”概念，仅按防御力百分比减伤计算，空军防御力减伤与通用防御力减伤统一收敛到最高85%

### 3.7 暂不设计分支的单位

潜艇：

- 保持 100 HP、50 ATK、0 DEF、8 SPD、1 RNG、12 COST。
- 0 阶只保留“只能攻击海上单位、攻击时除非对方也是潜艇否则无法反击”和对巡洋舰顺克等结构规则，不再附带潜航或其他正向兵种被动，时刻可被选中。（备注：同样无被动技能图标）
- 1 阶自动解锁【潜航】被动：（备注：这里先写暴露规则等等）；处于潜航状态时，发起的下一次攻击伤害提高25%/40%（备注：该被动仅在下一次脱战下潜之后重新激活蓄力）

建筑单位：

- 所有建筑单位（包括但不限于碉堡、岸防炮与天眼哨机）一律设置 rankLocked，不获得 XP，不参与军衔和专精，也不触发晋升回血。


航母：

- 独立海军航空平台，不属于巡洋舰专精；其逐阶奖励只强化航空平台职能，不获得舰炮或普通反击。

### 3.8 旧内容与旧军衔兼容

- 旧存档、旧战役和旧地图中的基础 type 继续按标准型恢复，不再需要 legacy variant profile。
- 旧存档中 rank = 0 的单位直接成为无被动标准型。
- 旧存档中 rank >= 1 且没有 specializationKey 的玩家单位进入待选择状态；不自动映射为任一专精。
- AI 单位按确定性评分立即选择；中立或无控制者单位按关卡预设或规则层默认分支处理。
- 旧版已经写入的统一军衔数值字段必须在迁移时清除并按新专精奖励重算，禁止与新奖励叠加。
- 新战役可以显式预设 specializationKey，但 rank 必须至少为 1；rank = 0 时禁止携带专精。
- 场景触发器默认仍以基础 type 匹配；只有精确需求才增加 specializationKey 条件。

| 防空炮     |   2 格 |  35 | 陆基机动区域防空           |
| 防空型驱逐舰  |   2 格 |  35 | 海上及沿岸区域防空          |
| 停滞者特殊能力 | 按现有范围 |     | 保留将领特色，但单个单位只计一个来源 |

明确不再提供防空：

- 野战炮
- 火箭炮
- 碉堡 mgNest
- 反潜型驱逐舰
- 普通巡洋舰/潜艇

### 4.3 高射机枪工事

- 所有阵营都可以建造，费用 2 金币。
- 永久存在，只保护所在格，不向邻格投射范围。
- 提供 30%防空火力
- 取消当前对所有地面远程攻击 +25% 防御的效果。
- 工事必须记录 campKey；不能再把 tile.fortification = flak 视为无归属公共防空。
- 与战壕共用 fieldFortification 槽，因此同一格只能二选一。
- 与城市机场使用不同字段，可以和机场共存。

建议把地块字段从字符串升级为：

    fieldFortification: { type: trench | flak, campKey: player1 }
    installation: { type: airfield, campKey: player1, ... }

兼容旧地图时，字符串工事恢复为 ownerKnown = false：

- 战壕继续对当前驻军生效。
- 高射机枪只保护本格，但不参与敌我范围推断。
- 首次被明确阵营单位修复/重建后写入所有权。

### 4.4 通用工事建造

工事建造不再是工程师主动技能。普通玩家通过选中己方普通地面单位或己方城市进入“建设”菜单。

战壕：

- 费用 2 金币。
- 普通地面单位在当前所在的己方陆地格修建。
- 立即完成，消耗建造者本回合全部行动。
- 与高射机枪互斥。
- 继续提供对近战攻击 25% 防御。

高射机枪：

- 费用 2 金币。
- 普通地面单位在当前所在的己方陆地格架设。
- 立即完成，消耗建造者本回合全部行动。
- 与战壕互斥。
- 可以建在带机场的城市上。

碉堡：

- 费用由 5 金币提高到 10 金币。
- 任意普通地面单位可在自身相邻 1 格的空己方陆地上发起施工。
- 不能建在城市、村庄、港口、水域或已有单位的格子。
- 立即生成可被攻击的脚手架。
- 脚手架在下一次所属阵营回合开始时转为碉堡，即仍需 1 个完整回合建成。
- 建造者只消耗发起施工的当前行动，不保存 builderId 锁定关系。
- 建造者下回合正常行动；即使建造者死亡，脚手架仍继续施工。
- 脚手架被摧毁则施工失败，不返还金币。
- 取消工程师专属碉堡冷却；价格、目标距离、脚手架风险和行动消耗构成通用约束。

碉堡作为独立 mgNest 单位占据地块，不占 fieldFortification 或 installation 字段。

现有“碉堡”对策卡继续保留，作为不支付 10 金币、无需等待施工回合的稀缺即时部署手段；其机会成本是抽牌和卡牌使用次数。通用建设与对策卡必须在文案上明确区分。

### 4.5 机场

机场是只能部署在城市上的城市设施：

- 使用 installation 槽，不使用 fieldFortification 槽。
- 可以与战壕或高射机枪共存。
- 战壕和高射机枪仍然彼此互斥。
- 同一城市最多一个机场。
- 机场随城市易主，不会因占领自动摧毁。
- 城市被轰炸瘫痪期间，机场不能发动指令或开始新建设。

机场建设：

- 标准建设费用暂定 10 金币。
- 通过己方城市面板直接发起，不要求城市上驻扎工程师或其他单位。
- 发起后进入施工状态，在下一次所属阵营回合开始时完成。
- 施工中的机场不能发动空军指令，但可被占领并随城市转移。
- 机场建设不占用城市驻军行动。

机场上限：

    airfieldCap = ceil(ownedCityCount / 3)

示例：

| 当前拥有城市 | 正常机场上限 |
|---:|---:|
| 0 | 0 |
| 1–3 | 1 |
| 4–6 | 2 |
| 7–9 | 3 |

- 标准对局地图配置必须在各阵营主初始城市预置 1 座机场。
- 机场数量统计包含已完成和施工中的机场。
- 新建机场时，如果当前机场数大于等于正常上限，禁止开始建设。
- 占领带机场的敌方城市时，机场完整转移。
- 占领导致机场数超过正常上限时，不拆除、不停用、不要求玩家选择放弃。
- 处于超限状态时不能继续新建机场，直到机场数重新低于当前上限。
- 城市数量下降导致已有机场超限时，同样保留全部机场但禁止新增。
- 战役和编辑器可显式覆盖初始机场与机场上限；标准对局使用上述公式。

### 4.6 工程师竞争力重做

建设能力通用化后，工程师不再依靠“别人不能造”获得价值，而是成为造得更省、守得更久、拆得更快的专业工兵将领。

工程师不再拥有独立的“挖掘战壕/高射机枪/建造碉堡”主动按钮，改为强化通用建设菜单。

技能一——工兵指挥：

前端仅显示：建造工事时获得专属折扣
-（备注：工程师载体发起战壕或高射机枪建设时，费用从 2 降为 1。
- 工程师载体发起碉堡建设时，费用从 10 降为 7，且立即完成。
- 工程师驻扎在城市时，该城市建设机场的费用从 10 降为 7。
- 折扣只在发起建设时判定；之后工程师离开或阵亡不补扣费用。
- 工程师仍消耗发起战壕/高射机枪/碉堡施工的当前行动，不获得免费行动经济。）

技能二——战地抢修：

- 主动技能，费用 3 金币，冷却 2 回合。
- 目标仅限相邻 1 格内拥有 HP 的己方建筑单位或碉堡脚手架，恢复 50% 最大 HP。
- 如果工程师位于拥有己方机场的城市，则该城市免疫空袭带来的负面效果。
- 战地抢修不能以工程师自身、步骑炮、舰船、航母或任何其他普通作战单位为目标。
- 同一目标每回合最多接受一次战地抢修。


工程师基础面板加成增强为 30% HP、25% ATK，不再保留 engineerConstruction、engineerBunkerCD 或锁定建造者的专属状态。

这样工程师的竞争力来自：

- 长期经济优势；
- 对高价值设施的抢修；
- 对敌方防御体系的定向拆解；
- 而不是垄断所有玩家都需要的基础建设功能。

### 4.7 防空计算

- 防空值统一表示百分比减伤，与普通防御力加算，仅对空军伤害生效；不再存在“层数”字段、层数上限或按层换算。
- 每一个实际受击地块分别收集覆盖该格的有效防空来源；同一来源对同一地块只计一次，所有不同来源的防空百分比直接相加。
- 高射机枪只在目标正好位于工事格时计入。
- 防空炮和防空驱逐舰按目标格到提供者的六角距离计入。
- 防空不产生航空队 HP、击落数或持续损耗。
- 结算顺序固定为：汇总防空百分比 → 应用空军上校“无视 15 个百分点防空”并将结果最低钳制为 0 → 与目标普通防御力相加 → 将空军总减伤钳制到最高 85%。
- 左上角单位属性栏中，防御力后的括号数值统一显示该单位当前所在格收到的防空火力保护值，例如 `防御 10%（防空 35%）`。括号只显示地块汇总后的原始防空百分比，不混入单位普通防御，不应用敌方空军上校的无视防空，也不显示 85% 上限钳制后的合计减伤；单位移动、防空来源移动/死亡/变更专精、工事建造/摧毁或阵营归属变化后必须实时刷新。

rules/antiAir.js 不再通过 unit.type === archer 等硬编码判断，而是读取能力标签：

    antiAir: { radius: 2, reduction: 0.35 }

工事则读取：

    providesSelfAA: true

## 五、WC4 式空军指令系统

### 5.1 机场的发起条件

空军指令由机场提供，不要求阵营拥有空军将领。

只有同时满足下列条件才显示并允许使用机场空军指令：

1. 当前城市属于当前行动阵营。
2. installation.type = airfield 且机场已经建成。
3. 城市未被轰炸瘫痪。
4. 天气不是雾天。
5. 该机场本回合尚未发动其他空军指令。
6. 对应指令冷却完成且金币足够。

发动任意空军指令后：

- 机场写入 airCommandUsedThisTurn = true。
- 本回合不能再从同一机场发动其他指令。
- 机场指令不消耗城市驻军、驻城将领或其他单位的 canAct、remainingMP 与主动技能次数；无论城市是否有驻军，行动成本都只由金币、机场本回合使用次数和对应冷却承担。
- 不占用 playerUsesThisTurn，不受普通对策卡每回合使用次数限制。
- “轰炸”类型的瘫痪效果改为：一座城市被轰炸一次时陷入【火海】状态（前端播放WC4式的着火动画），被轰炸2层时清除【火海】并陷入【瘫痪】，无法起飞空军或招募部队2回合

一座没有空军将领驻扎的机场仍然能够使用扫射、轰炸、空降；遭遇战还可使用侦察机。空的城市也将被纳入“轰炸”打击的合法目标

### 5.2 空军将领强化

空军相关将领继续挂载在普通地面单位上，但与“能否发动空军指令”完全脱钩。

空军上校强化机场的条件：

- （备注：上校载体存活；位于拥有已建成机场的己方城市）

满足条件时，只强化当前所在机场：

- 空军伤害提高20%，每使用一次空军该数值额外提高5%，最多叠加6层。
- 空军打击范围额外扩大1格。
-无视敌人15%防空火力。（备注：上校挂载在航母上时同样生效）

上校不消耗自身行动来发动机场指令，发动后仍可正常移动或攻击；但一旦离开机场城市，后续机场指令不再获得强化。

机场冷却和“本回合已使用”状态属于机场，不属于上校。上校转移到另一机场不会带走或重置原机场冷却。

### 5.3 统一空军配置

建议新增 rules/airCommands.js，作为空军价格、范围、冷却、伤害与目标规则的单一来源。

| 指令  | 发起者      |  费用 |            范围 |   冷却 | 目标       |
| --- | -------- | --: | ------------: | ---: | -------- |
| 扫射  | 机场       |   4 | 机场 5 / 上校强化 6 | 2 回合 | 单个敌军     |
| 轰炸  | 机场       |   5 | 机场 5 / 上校强化 6 | 2 回合 | 中心格及相邻六格 |
| 空降  | 仅机场      |  10 | 机场 5 / 上校强化 6 | 3 回合 | 可见的空陆地   |
| 侦察机 | 仅机场、仅遭遇战 |   4 | 机场 5 / 上校强化 6 | 2 回合 | 范围内任意地块  |

“冷却 2 回合”的精确定义：

- 在第 R 回合使用后，第 R+1 和 R+2 回合不可用。
- 第 R+3 回合重新可用。
- 扫射和轰炸各自独立记录，使用扫射不会重置轰炸冷却。
- 冷却保存在机场 installation 上，随城市占领一起转移。
- 不能只保存阵营级 cooldown，否则多机场和三人局会互相误锁。

建议字段：

    launcher.airCommandReadyRound = {
        strafe: 0,
        bombing: 0,
        airdrop: 0,
        recon: 0
    }

可用判定统一使用 getRoundIndex(gameState)。

### 5.4 空军伤害不能读取载体兵种攻击力

旧实现使用空军上校所在单位的 getEffectiveAttack() 计算空军伤害，会导致：

- 上校挂在野战炮上比挂在步兵上空军更强。
- 兵种克制、城市步兵增伤、骑兵冲锋等地面机制可能错误进入空中伤害。
- 专精上线后宿主选择会成为隐性最优解。

v2 改为独立空军伤害入口 resolveAirCommandDamage：

    最终伤害 =
        空军基础火力
        × 指令倍率
        × 可选的空军将领加成
        × 随机浮动
        × 目标防御乘区
        × 防空乘区

规则：

- 普通机场基础空军火力为 40。
- 航母扫射基础火力为 45，但它走第六章的普通攻击替代入口，不使用机场指令冷却。
- 不读取宿主单位 ATK、specializationKey、专精被动、冲锋、城市步兵攻击或 COUNTER_RELATION。
- 空军攻击不触发普通反击。
- 空军攻击不享受宿主单位的普通击中、击杀、吸血或再行动效果。
- 仍通过统一目标防御与护盾入口结算。
- 轰炸可以忽视部分正防御，但不能制造负防御。
- 伤害随机必须使用 gameState.rng，确保联机与重连确定性。


### 5.5 扫射

定位：单体收割和打击暴露的高价值目标。

- 基础倍率 1.0。
- 目标每损失 5% 最大HP，本次空军基础攻击力增加 1 点，上限 +15。
- 经过目标格防空后结算。
- 若发动者有驻军/将领，正常结算暴击，否则无法暴击，仅在期望附近有相对较窄的③浮动倍率乘区。
- 不瘫痪城市、不摧毁工事。
- 如果目标在动画完成前已不存在，指令仍消耗金币和冷却，但不重新寻找目标。

### 5.6 轰炸

定位：区域压制、攻城与破坏工事。

- 中心倍率 1.0。
- 相邻六格倍率 0.50。
- 无视中心目标 10% 防御力。
- 每个地块分别计算森林、护盾、防空百分比和目标防御，并遵守统一的 85% 空军总减伤上限。
暴击规则同扫射。
- 中心是敌方城市时，叠加【火海】
- 中心存在战壕或高射机枪时，轰炸后有 30% 概率摧毁该工事；使用 gameState.rng。
- 相邻格轰炸不摧毁工事，避免一次指令清除七个永久设施。

### 5.7 空降

空运 airlift 完全删除，改为空降 airdrop。

空降规则：

- 费用 10 金币。
- 只能由机场发动，不要求空军将领。
- 普通机场范围 5；有空军上校强化时范围 6。
- 目标必须在有效范围内、当前可见、为空的陆地非城市、非港口地块。
- 生成 rank = 0、specializationKey = null 的标准步兵。
- maxHp 读取当时 UNIT_CONFIG.infantry 的 0 阶标准面板，不再创建 maxHp = 100 的特殊步兵，也不绕过晋升直接生成突击专精。
- 根据落点防空火力百分比削减当前 HP。


- 落地回合 canAct = false、remainingMP = 0。
- 可以被敌方正常攻击和反击；下一次所属方回合恢复正常行动。
- 空降不会自动占领城市，因为目标不允许选择城市。
- 空降单位不免费挂载将领。
- 空降造成的单位数量优势已经很强，因此费用统一定为 10 金币，高于城市直接招募标准步兵的费用。

### 5.8 遭遇战侦察机

- 只在 skirmishFog 启用的遭遇战显示。
- 替代当前 scout 对策卡。
- 费用 4 金币、普通机场范围 5、上校强化范围 6、冷却 2 回合。
- 正常情况下揭示目标及 2 格范围，持续 2 个完整回合。
- 侦察中心的防空会降低效果：

|  中心防空火力 | 揭示范围 |   持续 |
| ------: | ---: | ---: |
|   0-25% |  2 格 | 2 回合 |
| 25%-50% |  1 格 | 2 回合 |
|   50%以上 |  1 格 | 1 回合 |

- 侦察机仅使中心1格的潜艇在揭示期间失去潜航状态。
- 不允许以侦察机完全替代反潜驱逐舰的持续侦测。
- 雾天天气停飞。

### 5.9 机场主动技能 UI

空军指令不再伪装成手牌：

- 机场图标必须有独立命中区域，点击城市地块或驻军本身不会自动展开空军指令。
- 只有点击已建成的己方机场设施后，selectedInstallation 才指向该机场。
- 此时在右下角主动技能区显示扫射、轰炸、空降；遭遇战额外显示侦察机。
- 点击其他单位、地块、工事或取消选择后，立即隐藏机场主动技能。
- 如果城市内驻有可生效的空军上校，界面显示“将领强化”，并预览强化后的火力、范围与防空修正。
- 每项显示金币、范围和“剩余 N 回合”冷却。
- 不可用项保持可见但置灰，并显示具体原因：
  - 机场尚未建成
  - 机场本回合已经出动
  - 城市被瘫痪
  - 雾天停飞
  - 金币不足
  - 冷却中
- 航母不使用机场主动技能面板；选中航母后按普通远程攻击流程操作。

- 不能普通反击；calculateCounterDamage 直接返回 0。
- 唯一攻击方式是单点扫射。
- 单点扫射直接作为航母的普通攻击替代，不进入机场主动技能系统。
- 可以锁定 5 格内合法的敌方陆地或海上单位。
- 选中航母后复用普通远程攻击范围高亮、悬停锁定和伤害预览。
- 点击目标后复用普通远程攻击的行动提交、canAct 消耗和联机协议框架。
- 航母可以先移动再扫射；扫射后 canAct = false。
- 单点扫射每个自身回合最多一次，不支付金币，也没有两回合机场冷却。
- 雾天天气下航母同样停飞。
- 航母不能轰炸、空降或侦察。
- 0 阶航母扫射使用 45 空军基础火力；后续只读取军衔映射和空军上校航空强化，不读取舰体舰炮 ATK 或其他舰上将领普通攻击加成。
- 空军上校可以挂载航母；挂载后按第五章规则令舰载机伤害提高 20%、每次使用后再提高 5%（最多 6 层）、射程 +1，并无视目标 15% 防空火力。
- 其他允许挂载的海军将领仍可登舰，但普通海军攻击加成不影响舰载机。
- 航母属于无分支常规单位，达到 1 阶时自动解锁舰载航空专精被动，不弹出选择；3 阶自动强化该被动，具体倍率由本章后续数值校准填写。
- 2 阶沿用全局 HP +15；由于航母没有舰炮 ATK，通用 ATK +10 等价转换为扫射基础火力 +10，不能写入无效舰炮面板。
- 4 阶沿用全局再生，并把通用暴击强化应用到舰载机扫射的③浮动/暴击入口；具体暴击数值待校准。

### 6.3 扫射伤害与防空

- 航母扫射使用与机场扫射相同的单体空军伤害规则。
- 目标已损生命转化攻击力的上限仍为 +15。
- 目标格的防空火力与普通防御力加算后降低伤害，并受全局 85% 总减伤上限约束。
- 不触发目标反击。
- 未挂载空军上校且尚未获得4阶暴击强化时，扫射不能暴击，只使用期望值附近较窄的③浮动区间；挂载空军上校或达到4阶后按对应③浮动/暴击规则结算。
- 不触发舰上将领的普通击中/击杀/吸血/再行动效果，但扫射造成伤害和击杀仍按普通军衔经验来源给予航母自身 XP，使其能够晋升。
- 对陆地和海上目标都不读取 carrier 的 COUNTER_RELATION 攻击行。
- 攻击预览必须显示“舰载机扫射”和防空减免后的预估伤害，不能显示成舰炮。

### 6.4 攻击表现

- classifyAttackPresentation 为 carrier 返回专用 FIRE_AIR_STRAFE。
- 锁定阶段复用远程攻击连线、射程格、目标描边和伤害预览。
- 确认攻击后，弹道起点是航母所在格，播放舰载机飞向目标的动画。
- 不播放舰炮炮口、炮弹或鱼雷效果。
- 动画结束后仍通过普通 attack action 的结果阶段应用伤害，保证联机时序一致。

### 6.5 克制关系

carrier 加入被攻击列：

- 潜艇攻击航母：顺克。
- 巡洋舰攻击航母：顺克。
- 岸防炮攻击航母：顺克。
- 驱逐舰攻击航母：普通。
- 陆地近战单位通常因表面规则不能攻击海上航母，不依赖矩阵硬拦截。

carrier 攻击行全部为 1；航母扫射使用独立空军伤害入口，不读取该行。

### 6.6 替换旧计划自动伤害

完全删除以下旧设计：

- 回合开始时自动寻找目标。
- 随机选取 3 格内目标。
- 固定造成 30 点伤害。
- 航母在没有玩家/AI选择攻击目标时凭空自动获得经验。
- 自动伤害触发普通击杀将领钩子。
- 航母机场式扫射/轰炸主动技能。
- 航母扫射/轰炸金币消耗与两回合冷却。

航母只在玩家或 AI 通过普通远程攻击锁定流程选择单点目标后产生伤害。

### 7.2 投毒

卡牌 ID：poison。

基础规则：

- 牌库数量：1。
- 目标类型：地图上当前有视野的任意单位。
- 可以选择敌军、友军或中立单位。
- 使用后目标立即获得【中毒】状态，但不会在使用瞬间扣血或传播。
- 初始剩余结算次数为 3。
- 每次目标所属阵营回合开始时，流失 15% 最大生命值。
- 中毒伤害可以致死。
- 每次中毒结算后，如果单位仍存活，则向身旁六格内所有尚未中毒的单位传播。
- 每个新感染单位都获得完整的 3 次结算，不继承传播者的剩余时间。
- 已经中毒的单位再次接触毒源时不叠层、不刷新持续时间。

伤害规则：

- 每次伤害 = max(1, round(unit.maxHp × 0.15))。
- 直接扣减 HP，不读取攻击力、克制、暴击、防御、地形或防空。
- 护盾不吸收中毒伤害。
- 中毒击杀不归属任何攻击者，不提供经验、击杀数、吸血、再行动或将领击杀触发。
- 单位因中毒死亡时仍走统一 destroy、胜负、士气和联机清理流程。

传播时序：

1. 某阵营回合开始时，对该阵营在此刻已经中毒的单位 ID 建立快照。
2. 只处理快照中的单位。
3. 每个单位先承受中毒伤害。
4. 如果该单位仍存活，再扫描身旁六格并感染所有尚未中毒的单位。
5. 新感染单位本次不扣血、不传播；最早在其所属阵营下一次回合开始时结算。
6. 原单位完成伤害和传播后，剩余结算次数减 1；归零时移除状态。

这套快照规则保证：

- 一个单位每次所属阵营回合开始最多传播一次。
- 同一回合中新感染单位不会立即继续向外传播。
- 不会出现 A 传 B、B 立刻传 C 的瞬间无限连锁。
- 三人局中，不同阵营单位仍按各自回合开始独立结算。

状态建议：

    unit._poison = {
        remainingTicks: 3,
        sourceCampKey: player1,
        infectedAtTurnCounter: 12,
        lastResolvedTurnCounter: null
    }

sourceCampKey 仅用于日志、动画和战役条件，不用于授予击杀收益。

目标范围与免疫：

- “任意单位”按玩法规则包含陆军、海军、防空炮、碉堡、岸防炮、无人机和航母，不额外建立写实免疫表。
- 空军指令没有棋盘单位，因此不能成为投毒目标。
- 运输状态单位以当前棋盘上的运输单位对象为目标，状态随其登陆后继续保留。

反制：

- 单位分散可以阻止继续传播。
- 在毒素结算前击杀/移除中毒单位，可以阻止其下一次传播。
- 现有【疗愈】卡在恢复生命后额外移除【中毒】，作为明确的稀缺反制手段。
- 牧师等普通治疗只恢复 HP，不自动解毒，除非其技能以后明确写出净化。

视觉与提示：

- 中毒单位显示紫绿色状态图标和剩余结算次数。
- 回合开始扣血显示独立的毒素伤害文本，不标记暴击。
- 传播时从毒源向每个新感染目标播放短距离毒雾连线。
- 状态说明必须显示“所属阵营回合开始结算”“可致死”“会向邻接单位传播”。

### 7.4 禁锢升级

- 牌库数量保持 2。
- 对指定敌方单位施加【禁锢】，持续到其下一次所属阵营回合结束。
- 被禁锢单位 remainingMP = 0，不能移动。
- 被禁锢单位 canAct = false，不能主动攻击。
- 被禁锢单位仍可按照普通规则反击，避免禁锢同时成为无风险集火的免反击效果。

### 7.5 地雷与水雷

【地雷】仍使用 landmine 卡牌 ID，但根据目标地块自动表现为地雷或水雷；牌库数量由 2 张提高到 4 张。

合法落点：

- 地雷：沿用现有规则，可放置在己方行政区内的空陆地地块；城市和已有单位的地块不可放置。
- 水雷：可放置在任意己方舰船相邻六格内的空海洋地块，不要求该海洋地块具有己方行政区归属。
- 舰船必须是仍在场且属于当前出牌阵营的海军单位；陆军运输船状态不视为“己方舰船”，不能作为水雷布设支点。
- 同一地块不能重复布雷，也不能与其他占格物或待完成的部署目标重叠。
- 选择陆地目标时显示“地雷”，选择海洋目标时显示“水雷”，但二者消耗同一张卡。

触发规则：

- 敌方单位进入布雷地块时立即触发并清除；己方单位经过不会触发。
- 地雷可由进入陆地的敌方地面单位触发；水雷可由进入海洋的敌方舰船或运输状态单位触发。
- 伤害仍以 100 为基础值，但不再是真实伤害，必须受到触发单位当前防御力影响。
- 实际伤害为 `round(100 × 防御乘区)`，防御乘区沿用全局最低伤害倍率下限；计入单位固有防御、军衔、士气、将领及光环、地形和其他通用防御修正。
- 地雷/水雷没有攻击者和兵种类型，因此不计算兵种克制、攻击方增伤、暴击、反击，以及“仅对近战/远程/空军生效”的定向防御；高射机枪和防空炮也不能削减水雷伤害。
- 地雷/水雷伤害仍不产生击杀者、经验、击杀数或将领击杀触发。

表现与信息：

- 水雷使用独立的水面图标、爆炸文字和日志名称，但复用现有 landmine 的存档主体与触发流程。
- 地雷和水雷对其所属阵营的所有玩家始终显示低调但清晰的己方布雷标记，不受战争迷雾遮蔽；陆地与海洋标记必须能一眼区分。
- 敌对阵营看不到未触发的布雷标记，即使该地块处于其当前视野内；触发后才向所有相关客户端播放爆炸效果并写入战斗日志。
- 前端不得仅凭 tile 上存在 `_minePlanted` 就渲染标记，必须先比较 `_mineCampKey` 与当前观察者阵营；网络载荷可以同步必要状态，但渲染层必须执行同样的信息权限判断。
- 观战者默认只看到其当前跟随阵营能够看到的布雷标记；全知观战/回放模式如需显示全部地雷，必须使用显式的 omniscient 开关，不能沿用普通玩家视图。
- 联机行动必须同步布雷类型、所属阵营、地块坐标、触发单位和防御结算后的实际伤害。
- AI 使用地雷卡时同时评估陆地交通节点和己方舰船附近的海上航道；不能读取战争迷雾下的敌军路径来作弊布雷。

## 八、地形专精被动：取消

原计划拟增加：

- 骑兵平原攻击 +10%
- 步兵森林防御 +10%
- 炮兵山地攻击 +10%
- 驱逐舰对岸攻击 +15%
- 潜艇深水防御 +10%

v2 全部取消，原因如下：

1. 轻骑冲锋与重骑铁蹄已经构成两套独立机制，再加平原增伤会形成过度叠层。
2. 步兵森林对远程已有地形与森林掩蔽，再加 10% 会把防御持续推向下限。
3. 炮兵山地增伤会和风天射程/伤害叠加，制造固定最佳炮位。
4. 驱逐舰对岸增伤侵占对岸支援巡洋舰的职能。
5. 潜艇同时拥有潜航、深水防御和高速度时过于难以处理。
6. 1 阶专精已经承担战术分化，不需要再给所有兵种叠一层地形被动图标。

保留现有地形移动、防御、天气和森林远程掩蔽即可。

## 九、AI 设计

### 9.1 标准招募与 AI 专精

AI 招募时只决定基础兵种家族，和玩家一样创建 0 阶无被动标准型。单位达到 1 阶后，AI 再根据战场需求立即选择专精：

- 步兵：
  - 己方关键城市缺驻军或城市受威胁：卫戍步兵。
  - 附近敌方城市/工事需要突破：突击步兵。
- 骑兵：
  - 敌方炮兵多、存在侧翼路线：轻骑兵。
  - 正面需要承受反击：重骑兵。
- 炮兵：
  - 敌方高防、城市和工事多：野战炮。
  - 敌方单位聚集度高：火箭炮。
  - 敌方拥有可用机场或航母，且己方关键单位缺少区域防空：防空炮。
- 驱逐舰：
  - 敌方存在潜艇或潜艇威胁评分高：反潜型。
  - 敌方拥有可用机场或航母：防空型。
- 巡洋舰：
  - 当前目标是敌方舰队：制海型。
  - 当前目标是登陆或沿岸城市：支援型。
AI 选择防空炮分支时，应限制数量不超过己方有价值城市/舰队核心的实际防空需求，避免在敌方无空军时浪费炮兵晋升。

潜艇和航母等无分支常规单位不进入专精选择；AI 在1阶/3阶自动应用职能被动及强化，并在2阶/4阶应用通用奖励。所有建筑单位统一保持 rankLocked。

### 9.2 建设与机场

- AI 按 ceil(城市数 / 3) 计算正常机场上限。
- 没有机场且未超限时，优先在远离前线、交通位置较好的核心城市建设第一座机场。
- 机场已经超限时不拆除，但停止新增建设。
- 敌方近战压力高时建设战壕；敌方空袭价值高时在机场或关键城市建设高射机枪。
- 碉堡只在预计能持续控制的 chokepoint 建造，并计入 10 金币和一回合脚手架风险。
- 普通 AI 可以建设全部工事，不依赖抽到工程师。
- 工程师 AI 应把建设折扣、立即完成碉堡、舰船/建筑抢修和驻城机场免疫空袭计入行动评分。

### 9.3 机场空军与空军上校

AI 从每座可用机场独立选择是否发动指令：

- 扫射优先残血将领、高价值炮兵、防空炮。
- 轰炸优先三个以上敌军聚集、敌方城市、工事中心。
- 空降优先安全侧翼、切断补给、支援即将发生的城市战。
- 侦察优先未探索敌方城市方向和疑似潜艇海域。
- AI 必须读取目标格累计防空火力与普通防御力并评估 85% 总减伤上限后的实际伤害，不能只看未减免基础伤害。
- 如果空军上校驻扎在某座机场城市，使用强化后的范围、火力和防空修正重新评分。
- 空军上校是否驻守机场是强化决策，不是机场能否出动的前置条件。
- 空军上校挂载航母时，AI 使用同一套 20% 初始强化、每次 +5%（最多 6 层）、射程 +1 和无视 15% 防空火力的规则重新评估登舰收益。

### 9.4 航母

- 航母保持在巡洋舰/驱逐舰保护范围内。
- 有潜艇威胁时优先靠近反潜驱逐舰。
- 有敌方空军时优先靠近防空驱逐舰。
- 航母按普通远程攻击流程寻找 5 格内单点扫射目标。
- 目标评分优先残血、高价值炮兵、防空炮和敌方将领，并读取目标格防空后的实际伤害。
- 航母没有轰炸和机场冷却，不得进入机场主动技能决策。
- 航母达到 1 阶和 3 阶时自动应用舰载航空被动及强化，不进入专精选择；2阶/4阶应用对应通用奖励映射。
- AI 必须保持远程距离，不能因为扫射使用 attack action 就把航母当舰炮单位贴脸。

### 9.5 投毒

- 优先选择高最大生命、剩余结算机会充足且邻接多个敌军的中心单位。
- 评估传播时必须把友军、中立单位也纳入，避免毒素在下一轮反向感染己方密集阵型。
- 已中毒目标权重为 0，因为重复投毒不会刷新持续时间。
- 敌方持有疗愈卡的可见信息不能被 AI 作弊读取；只按公开状态和单位聚集度评分。
- 如果己方单位已经大面积中毒，AI 应提高疗愈卡的保留与使用权重，并主动分散单位。

### 10.3 回合钩子

当前 getRoundIndex = floor(turnCounter / factionCount)，适合表示完整轮次。

回合开始：

- 重置当前阵营机场 installation.airCommandUsedThisTurn。
- 对当前阵营回合开始前已经中毒的单位建立快照并结算中毒。
- 中毒结算和死亡清理先于卫戍步兵的城市回复、天气回复、港口维修等恢复效果。
- 完成 constructionReadyRound 已到期的机场和碉堡脚手架。
- 不通过递减计数修改冷却；直接比较 readyRound，减少三人局和重连误差。

发动扫射/轰炸：

- readyRound = currentRound + 3。
- 例如第 4 回合使用，第 5、6 回合不可用，第 7 回合可用。

空降建议 readyRound = currentRound + 4；侦察机 readyRound = currentRound + 3。

### 10.4 联机动作

机场主动技能新增独立 action：airCommand。航母扫射继续使用普通 attack action，仅在结果类型中标识 carrierStrafe。

专精选择新增独立 action：chooseSpecialization，至少携带 unitId、基础 type、当前 rank、specializationKey 和选择前状态签名。接收端必须重新校验单位所属阵营、rank >= 1、当前 specializationKey 为空且分支属于该基础 type；选择结果通过统一重算入口应用，不能同步一组可重复叠加的属性差值。

发送内容至少包括：

- launcherKind = airfield
- launcherTileQ/launcherTileR
- commandId
- targetQ/targetR
- goldCost
- readyRound
- 由 gameState.rng 产生的确定性结果
- 伤害/空降/侦察结果数组
- 被摧毁工事

发起端完成合法性校验和 RNG 推进，接收端应用结果并校验发起者、目标和费用。不能让两端各自调用 Math.random。

火箭炮溅射、空军轰炸、工事摧毁和空降生成单位都必须走明确的联机结果广播。

通用建设新增 construction action，必须携带建设类型、发起单位或城市、目标格、实际费用、constructionReadyRound 和工程师折扣来源。接收端重新校验机场上限、设施槽和金币，城市占领动作必须同步转移 installation.campKey。

### 10.5 旧存档卡牌迁移

恢复旧存档时：

- 手牌中的 diveStrafe、carpetBomb、airlift、airstrike、airdrop、scout 从手牌移除。

- 空军上校不再获得指令 UI；机场根据自身 installation 状态获得指令 UI。
- 已存在的 100 HP 空降步兵继续按旧 maxHp 恢复，不自动升级为突击步兵。

- 无机场、机场施工中、城市瘫痪、非己方城市、雾天时不能发动。

- 上校离开机场城市后，该机场恢复普通火力/范围。
- 空军伤害不受宿主步兵/骑兵/炮兵面板影响。
- 扫射和轰炸冷却互不影响。
- 第 R 回合使用后第 R+1/R+2 禁用，第 R+3 可用。
- 航母没有机场式冷却或金币消耗，每个自身回合最多通过 attack action 扫射一次。
- 航母可以移动后扫射，但不能反击。
- 航母只能锁定单点目标，不能轰炸、空降或侦察。
- 航母复用远程攻击范围、锁定连线和伤害预览，预览显示防空后的扫射伤害。
- 空军上校可以挂载航母，并正确提供伤害 +20%、每次使用后 +5%（最多6层）、射程 +1 和无视15%防空火力。
- 无上校航母扫射不能暴击；挂载上校或获得4阶暴击强化后按对应③浮动/暴击规则结算。
- 防空按每个轰炸地块分别结算。
- 空降生成 0 阶无专精标准步兵，落地当前 HP 按目标格累计防空火力百分比削减，并与普通防御共同遵守85%总减伤上限。
- 空降落地回合不能行动。
- 侦察只在遭遇战出现，防空正确缩小范围和持续时间。
- 侦察卡不再进入牌库。

### 12.3 建设与工程师测试

- 机场只能建在己方城市的 installation 槽。
- 机场可以与战壕或高射机枪共存。
- 战壕和高射机枪彼此互斥。
- 碉堡作为独立单位不占两个设施槽。
- getAirfieldCap 对 0/1/3/4/6/7 城返回 0/1/1/2/2/3。
- 标准对局每个阵营配置一座初始机场。
- 占领机场城市可以导致超限，机场继续可用但不能新增。
- 城市丢失导致超限时不自动删除机场。
- 普通单位可以花费 2/2/10 金币建设战壕/高射机枪/碉堡。
- 碉堡脚手架一回合后完成，建造者下一回合不被锁定。
- 建造者死亡不取消脚手架，脚手架被摧毁则施工失败。
- 工程师建设费用正确变为 1/1/7，碉堡立即完成，驻城机场建设为 7。
- 工程师战地抢修花费3金币、冷却2回合，仅作用于相邻的己方建筑单位或碉堡脚手架并恢复50%；工程师自身、舰船、航母及任何普通作战单位均不是合法目标；同一目标每回合最多接受一次。驻有工程师的机场城市免疫空袭负面效果。
- 发动机场指令不改变城市驻军或驻城将领的 canAct、remainingMP 和主动技能次数。

### 12.4 投毒与卡牌测试

- 只能选择当前有视野的单位，但不限制敌我阵营。
- 使用瞬间只附加状态，不立即扣血或传播。
- 每次准确扣除 15% 最大生命，忽略护盾和防御并可致死。
- 每个中毒状态恰好结算 3 次。
- 每次存活结算后感染邻接六格内所有未中毒单位。
- 新感染单位获得完整 3 次，不继承传播者剩余次数。
- 新感染单位不进入当前回合开始快照，不会立即扣血或二次传播。
- 已中毒单位重复接触不叠层、不刷新。
- 中毒死亡不授予经验、击杀数和将领击杀触发。
- 中毒单位死亡后不传播。
- 疗愈在恢复 HP 后移除中毒；普通治疗不净化。
- 双人、三人局分别按单位所属阵营回合开始结算。
- 存档恢复和联机同步后 remainingTicks 与传播时序一致。
- 标准模式与遭遇战牌组均为 20 张，地雷恰好 4 张，遭遇战不再追加侦察卡。
- 地雷只能放在合法己方陆地区域；水雷只能放在己方舰船相邻的空海洋格，运输状态陆军不能提供水雷落点。
- 敌方地面单位、舰船和运输状态单位分别正确触发对应地雷/水雷；友军经过不触发。
- 100 点基础地雷伤害会被目标的通用防御修正削减，但不计算兵种克制、暴击、定向近战/远程防御或防空。
- 同阵营玩家始终可见己方地雷/水雷标记，敌方即使取得地块视野也看不到；触发后双方均收到正确特效与日志。
- 联机重连、阵营视角切换和观战跟随不会泄露敌方未触发地雷；全知模式仅在显式开启时显示全部标记。

### 12.5 联机与回归

- 双人、三人局 roundIndex 冷却一致。
- 主机/客机空军 RNG、工事摧毁和 AoE 结果一致。
- 重连后机场冷却、机场上限、施工状态、上校强化、specializationKey、rank reward、防空工事所有权一致。

## 十四、验收标准

1. 玩家招募步、骑、炮、驱逐舰、巡洋舰时只创建 0 阶标准型，招募面板不出现专精二级选项。
2. 0 阶普通单位不附带任何正向兵种被动；达到 1 阶后才在右下角主动技能区按该兵种实际分支数作出不可逆的专精选择，炮兵为三选一。
3. 军衔奖励按新合同执行：1阶专精/自动被动、2阶通用 HP+15 与 ATK+10、3阶专精二次强化、4阶再生与暴击强化；一次 XP 结算无论跨越多少阶都只恢复一次25%已损生命。
4. 不存在同时拥有更高面板、更低费用和无条件强被动的上位专精。
5. 野战炮和火箭炮都不会被防空规则识别。
6. 高射机枪是便宜单格点防空，防空炮是炮兵 1 阶可选的纯防空区域分支，防空驱逐舰是海上区域防空；所有防空统一使用百分比累加规则并与普通防御共同受 85% 总减伤上限约束。
7. 没有空军将领时，已建成且可用的机场仍能发动空军指令；空军将领只强化所在机场或所挂载的航母。
8. 标准对局每阵营预置一座机场，新增上限始终按 ceil(城市数 / 3) 判定，占领溢出不删除但禁止继续新增。
9. 机场可与战壕或高射机枪共存，后两者互斥。
10. 战壕、高射机枪和碉堡对所有阵营开放；碉堡 10 金币、一回合完工且不锁定建造者下一回合。
11. 工程师通过建设折扣、碉堡立即完成、战地抢修和驻城机场免疫空袭保持独特竞争力。
12. 空军指令不进入手牌，不消耗普通卡牌使用次数。
13. 空降生成 0 阶无专精标准步兵，落点防空只削减当前 HP。
14. 遭遇战侦察机完全取代侦察对策卡。
15. 扫射和轰炸分别经过两个完整回合后才能再次使用。
16. 航母没有舰炮和反击，只能通过普通远程锁定流程执行每回合一次的单点扫射；其1/3阶自动强化、2/4阶通用奖励映射和空军上校登舰强化均按第六章执行。
17. 投毒持续结算 3 次、每次流失 15% 最大生命，并通过回合开始快照保证新感染者不会立即继续传播。
18. 疗愈是明确的解毒手段，中毒击杀不触发任何攻击者收益。
19. AI、战役、联机、重连和旧存档共用同一规则数据，不存在前端文案与结算数字的第二份配置。
