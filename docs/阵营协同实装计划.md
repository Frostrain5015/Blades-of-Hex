## 任务 A · 神谕封顶（3 阶 / 50%）

**目标**：神罚真伤最高停在 **50%**（第 3 阶），之后不再增强；解决先前评审指出的「升阶到 100% maxHP 真伤滚雪球」问题。

**改动（`rules/celestine.js`，唯一数值源）**：
- `CELESTINE_ORACLE_BALANCE.stagePercents` 由 `[0.10, 0.30, 0.50, 0.70, 1.00]` **改为 `[0.10, 0.30, 0.50]`**。
- `getOracleStage` / `getOracleDamagePct` 已用 `Math.min(len,…)`/`Math.min(len-1,…)` 夹取，数组缩短后**自动**封顶在 3 阶 / 50%，无需改函数体。
- `CELESTINE_FACTION_PASSIVE.description` 由 `stagePercents[0]~[4]` 派生，缩短数组后自动显示「10%~50%」。检查是否有别处硬编码 `[4]` 或「100%」。

**风险 / 测试**：
- `test/celestine.test.mjs` 中断言最高阶百分比、`getOracleStage(activeRounds)` 在 12/16/20 回合的返回值需更新为封顶 3。
- roundsPerStage 保持 4（第 9 回合起即恒定 50%）。

**工作量**：约 1 处常量 + 测试更新。低风险，先做。

## 任务 B · 诺克提斯【血月之夜】

**机制回顾**（详见规划文档四·7）：≥2 名诺克提斯将领存活 → 天穹变血月（激活即满、**不升阶**、将领跌破 2 名即月落）。两柱：
- **永夜（压敌）**：本阵营的**敌方**单位 **禁疗**（一切回复无效）+ 每整轮**持续掉血**（月蚀真伤，maxHp×`dotPct`）。
- **月之眷属（增己）**：本阵营单位攻击力 +`atkBonusPct`。

### B1. 规则层 `rules/noctis.js`（新建，对标 eagle.js/celestine.js）
- `isNoctisCommanderId/Unit`、`getLivingNoctisCommanders(gameState, campOrKey)`、`hasNoctisSynergyActive(gameState, camp)`（≥2，无身份去重）。
- `NOCTIS_BLOODMOON_BALANCE = { dotPct, atkBonusPct }`（唯一数值源）。
- `isBloodMoonHealSuppressed(unit, gameState)`：`unit` 所属阵营与**任一**处于血月激活态的诺克提斯阵营敌对 → true（用 `diplomacy.isHostile`，与 eagle 同范式，兼容 3p）。
- `getBloodMoonAttackBonus(unit, gameState)`：`unit` 为诺克提斯阵营且本阵营血月激活 → `atkBonusPct`，否则 0。
- `resolveBloodMoonPulse(gameState, campKey)`：每整轮对该血月阵营的所有敌方存活单位结算一次 `maxHp×dotPct` 真伤（`applyDamage({source:'true', attacker:null})`），返回打点载荷供广播/表现。**月蚀真伤不触发任何「受到伤害」类计量/反伤/协同**（避免连锁）。

### B2. 禁疗接入（`js/Unit.js`）
- `heal(amount)`：开头加 `if (isBloodMoonHealSuppressed(this, _gameState)) { /* 可选：飘「禁疗」字 */ return 0; }`——**单点覆盖绝大多数回复**。
- **额外两处直接改 hp、不走 heal() 的路径**需单独 gate：
  1. 牧师治愈灵光·**临终迸发**（`Unit.js:939` 直接 `this.hp += burst`）——加同一 suppressed 判定。
  2. 奥雷利亚**救援**（`Unit.js:975` 把 hp 抬到 40% maxHp）——**决策点③**：血月是否封锁敌方救援？默认**不封锁**（救援是「拦截死亡」而非治疗）。
- 检查军衔 regen（`gameLogic.js:951`）、城市/雨天回血（`:909/916/1209`）、field repair（`:3473`）、击杀回血（`:2576`）——它们都调 `unit.heal()`，单点拦截即可，无需逐个改。

### B3. 每轮掉血 + 攻击加成 + 激活/失效（`js/gameLogic.js`）
- `isRoundAnchor` 块内（神谕脉冲旁）：对每个 `hasNoctisSynergyActive` 的阵营调 `resolveBloodMoonPulse`，收集 DoT 打点进 `_pendingBloodMoonEvents`，随广播下发。
- 攻击加成：在 `getEffectiveAttack()`（`Unit.js:488-513`，与誓言同点）叠乘 `getBloodMoonAttackBonus`；航母/无人机路径（`:708`）按需同步。
- 血月**升起/落下 Hero**：激活态跨越 0↔1 时发一次全屏 Hero（首次升起用完整动画，之后仅天色维持）；沿用神谕的 `stageChanged` 式边沿检测思路，用 `gameState._bloodMoonActive[campKey]` 记忆。

### B4. 表现层
- 新建 `js/noctisBloodMoonPresentation.js`：血月天幕（绘于战争迷雾之上、全图可见，参考神谕神像叠加层）、月蚀掉血飘字、升月 Hero。
- `factionSynergies.js` 的 `NOCTIS_FACTION_SYNERGY.skillImplemented` 改 **true**；补 `effect` 描述块（供 HUD/图鉴）。
- HUD：血月徽标 + 剩余生效条件（≥2 将领）提示。

### B5. 测试 `test/noctis.test.mjs`（新建）
- 激活/失效阈值（2↔1 将领切换）；3p 敌对判定。
- 禁疗：敌方各类回复（heal/regen/雨天/临终迸发）在血月下归 0；己方不受影响。
- DoT：每整轮敌方 maxHp×dotPct 真伤；月蚀真伤不触发受伤计量。
- 攻击加成：诺克提斯单位 +atkBonusPct，月落即恢复。

## 任务 C · 天衡【借日】（主动对策卡，一局 1 张）

**机制回顾**（详见规划文档五·7）：协同激活（≥2 天衡将领）→ 发 1 张【借日】入手牌，一局仅此一张。释放→**本阵营全体单位**行动力回满、重新可行动（全军第二轮）；**下一整回合本阵营全体禁锢**（偿还）。

### C1. 卡定义 `rules/cards.js`
- 新增 `borrowDay`：`{ id:'borrowDay', name:'借日', icon:'⚖️', targeting:'selfInstant'（无目标，即时全局）, desc:… }`。
- resolve：对释放方阵营**所有存活单位**执行 `canAct = true; remainingMP = 满值`（沿用回合刷新时的满行动力计算）；清除本回合的 `_imprisoned` 等本回合锁（**决策点⑦**）。置 `gameState._borrowDayImprison[campKey] = true` 作为下回合偿还标记。返回结算载荷。

### C2. 发卡 · 一局一张（`js/gameLogic.js`）
- 协同**首次激活**时（≥2 天衡将领存活且 `!_borrowDayGranted[campKey]`）：`playerHands[campKey].push('borrowDay')`，置 `_borrowDayGranted[campKey]=true`。用掉不补。发卡时若已跌破 2 名则不发。
- 免弃牌：`gameLogic.js:4259` 判定里加 `borrowDay`（同 orbitalStrike，用后按需处理）。
- 连横不可复制：`gameLogic.js:4619` 排除列表加 `borrowDay`。

### C3. 偿还 · 下回合全体禁锢（`js/gameLogic.js` 回合刷新 ~1142）
- 回合开始刷新 `canAct` 时：若 `_borrowDayImprison[campKey]` → 该阵营全体 `canAct=false` 且置 `_imprisoned=true`（**决策点⑤**：是否连攻击一并禁掉＝完整「不可行动」，还是仅沿用 `_imprisoned` 的「不可移动」）。随后清除该标记（仅偿还一个整回合）。

### C4. 表现层
- `js/tianhengBorrowDayPresentation.js`（新建）：断裂星盘 Hero、力场涟漪扫过全军、下回合全体禁锁图标。
- `factionSynergies.js` 的 `TIANHENG_FACTION_SYNERGY.skillImplemented` 改 **true**；`effect` 描述块。

### C5. 测试 `test/tianheng.test.mjs`（新建）
- 发卡：协同激活发且仅发 1 张；用后不补；跌破 2 名不发。
- 释放：全体 canAct/remainingMP 回满。
- 偿还：下一整回合全体禁锢，之后恢复。
- 连横不可复制、免弃牌。

## 联机 / 确定性

血月 DoT、升月 Hero、借日结算都必须像神谕/eagle 一样走 **pending 事件队列 + broadcastAction**，两端确定性重算、用 `presentationEventId` 去重，避免主客机不同步。新增的 `gameState._bloodMoon*` / `_borrowDay*` 需纳入快照同步。

1. **任务 A**（神谕封顶）——独立、低风险，先合。

每个任务：规则层 + 测试先行（node --test），再接 gameLogic/Unit，最后表现层；每步 `npm test` 绿灯后再进。
