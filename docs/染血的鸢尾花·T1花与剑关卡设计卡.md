# 《染血的鸢尾花》T1「花与剑」关卡设计卡

本文将 T1 分为互不混用的设计层和实现层。设计层说明玩家应经历什么；实现层记录当前战役运行时必须精确保留的行为。

## 一、设计层

### 1. 关卡命题

玩家在一场安全、庄严且可信的校场训练中学会选择、移动和攻击，同时自然接受摄政府的军纪叙事。结尾让马库斯先说“持剑者决定方向”，又说“军令会告诉方向”，把尚未被察觉的矛盾埋进玩家亲手完成的授章仪式。

### 2. 原型问题

- **问题**：新玩家能否在不阅读长篇规则说明的情况下，依次完成选择、移动、攻击和列队？
- **核心动词**：选中 → 移动 → 攻击。
- **保留条件**：玩家只凭高亮和短对白即可完成全流程，并能复述“先站对位置，再出剑”。
- **返工条件**：玩家需要猜测可操作单位、目标格或攻击对象，或在授章前误以为关卡已经结束。

### 3. 体验节拍

| 节拍 | 类型 | 强度 | 作用 |
|---|---|---:|---|
| 校场训话 | 引入 | 0.1 | 建立马库斯的可信度与军纪语境 |
| 选择新兵 | 教学 | 0.2 | 单独学习选中单位 |
| 移动中央 | 发展 | 0.3 | 理解行动范围与目标格 |
| 攻击训练靶 | 小峰值 | 0.5 | 完成第一个完整战术动作链 |
| 穿越大校场 | 复习/自主运用 | 0.35 | 用三名新兵跨多个回合自主规划行军 |
| 授章仪式 | 释放/叙事 | 0.1 | 三人获得 5 EXP、实际晋升一级，并植入政治误读 |
| 方向问答 | 叙事钩子 | 0.25 | 留下日后可重新解释的矛盾 |

### 4. 路径与门控

- **关键路径**：开场训话 → 选择指定新兵 → 移至中央训练位 → 攻击训练靶 → 三人沿中央草道跨回合北上 → 授章。
- **黄金路径**：沿林带与山脊之间的开阔草道推进；玩家可自行决定三人的移动顺序和具体落点。
- **门控原则**：首次选择、移动和攻击逐步开放；掌握动作链后解除严格操作锁，让玩家在大地图上自主复习。
- **失败语义**：本关不以误操作惩罚玩家；错误输入被操作锁拒绝，玩家停留在当前教学阶段。

### 5. 设计不变量

- 高级系统全部关闭；玩家只能接触基础棋盘选择、移动和攻击。
- 严格教学阶段任一时刻只能有一个监听器接受推进操作；自由行军阶段只保留全员列队监听器。
- 操作锁出现时必须同时给出真实可执行的单位或地块高亮。
- 攻击完成后必须先激活“列队授章”，再完成“基础训练”，避免目标系统提前判胜。
- 三名新兵必须同时位于授章队列，不能仅凭最后一人的移动事件完成关卡。
- 塞维鲁的军纪承诺必须听起来真诚；本关不提前使用阴谋家语气。
- 马库斯最后两句话必须并置，伏笔来自含义冲突而非作者旁白揭示。

### 6. 留白与恢复优先级

- **可调整**：对白字数、等待时间、森林装饰位置、训练靶生命值。
- **可安全假定**：本关无敌军反击、无硬失败、无支线奖励。
- **不可丢失**：教学动作顺序、目标切换顺序、全员列队检查、授章仪式和“持剑者/军令”矛盾。
- **恢复优先级**：可完成教学链 > 不提前结算 > 操作可读性 > 叙事伏笔 > 装饰。

## 二、实现层复现规格

### 1. 棋盘与参与者

- 当前 schema：v4；经典六角棋盘，半径 4，晴天，回合上限 4。
- 玩家阵营参与回合；训练靶阵营不参与回合但与玩家敌对。
- 三名新兵属于 `new_recruits`；唯一训练靶属于 `training_targets`。
- 三名新兵从南侧营地出发，授章区域 `oath_line` 位于北侧旗台前，任一人的最短路线不少于四格。
- 中央草道保持平原；森林、山脊与两座补给村落成簇分布在外围，形成大校场边界和视觉地标。
- 马库斯和塞维鲁在开场时已经位于地图上，均不可行动。

### 2. 阶段状态机

```text
start_story
  └─ __begin_selection → begin_selection
       └─ recruit_selected
            └─ recruit_reached_center
                 └─ training_strike
                      └─ assembly_complete（自由行军）
                           └─ __complete_lesson → finish_lesson
```

- 严格教学链除 `start_story` 外开场关闭，由上一阶段显式启用下一阶段。
- 三个到位监听器可开场监听，但必须同时满足 `take_oath` 已激活；到位后写入对应变量并锁定该新兵移动。
- 三个汇合门分别处理“最后到位者”为剑手、花手或旗手的情况；满足其余两个到位变量后先显示共同的列队叙事句，并把玩家的下一次点击明确跳转到 `__begin_oath`，授章对白只保留一份。
- `eventNextIs` 的每个值必须恰有一个 `showStep.next` 来源和一个接收者。

### 3. 行为关键规则

- **RULE-ORDER-01**：`training_strike` 中先将 `take_oath` 设为 `active`，再将 `learn_basics` 设为 `completed`。
- **RULE-GATE-01**：每个 `boardLock:true` 的步骤必须提供单位或地块高亮，且该目标在当时可执行；自由行军开始后解除操作锁。
- **RULE-ASSEMBLY-01**：每名新兵首次进入 `oath_line` 时写入独立到位变量并锁定移动；三条简单事件汇合门覆盖任意最后到位者，显示同一列队句并发出 `__begin_oath` 显式跳转，随后统一进入一次性授章阶段。
- **RULE-PROMOTION-01**：授章阶段必须通过编辑器动作 `addUnitXp` 给 `new_recruits` 单位组各增加 5 EXP，并保留晋升动画；验收以三名单位实际达到一级为准，不能只用对白宣称晋升。
- **RULE-SAFETY-01**：训练靶不能反击；未轮到的新兵不可行动。
- **RULE-SCOPE-01**：战术卡、征募、增援、将领技、空军指令、天气效果、士气、工事、战争迷雾和盟军视野全部关闭。
- **RULE-DURATION-01**：地图半径为 4，三名新兵从南侧营地到北侧授章区至少跨越四格；标准路线需要三个玩家回合，目标体验时长为 5–8 分钟。

### 4. 胜利与结算

- `learn_basics` 与 `take_oath` 都是主要目标。
- `take_oath` 初始隐藏；基础攻击完成后才显示。
- `finish_lesson` 完成 `take_oath`，由目标系统触发胜利。
- 无额外星级条件；通关固定获得基础一星。

## 三、验证清单

- 原始关卡声明 schema v4，归一化后 `validateLevel` 无错误、无警告。
- 所有高级机制均为 `false`，不能依赖默认值。
- 错点其他单位、地块或目标不会跳过当前阶段。
- 正常路径能够从开场走到结果界面。
- 任一 `next` 不得悬空，任一阶段启用动作不得引用不存在的触发器。
- 三名新兵未全部列队时不得结算。
- 浏览器测试应确认马库斯、塞维鲁的姓名和立绘正确，并走完实际点击路径。

## 四、抽取记录

- **保留**：动作顺序、目标状态顺序、精确列队人数、阶段启用关系、机制开关和人物在场性。
- **抽象**：具体坐标在设计层被抽象为中央、左翼、右翼，仅在实现层保留其行为意义。
- **省略**：森林装饰坐标、旗帜素材路径及纯展示样式不进入设计层。
- **新增恢复指引**：明确了不可丢失项和恢复优先级。
- **验证方式**：本轮由同一执行者进行自审和自动化测试，不宣称已通过独立盲恢复验证。
